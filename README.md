# 에이전틱 개발 마스터 교재 시리즈

> **Agentic Development Master Textbook Series**
> 대학생·신입 개발자·기획자·디자이너를 위한 AI 에이전트 코딩 도구 완전 정복 교재

---

> **비즈니스 생산성을 위한 일분일초가 아쉬운 직장인을 위하여.**
> 많은 기업이 혁신을 위해 '클로드(Claude)'를 도입하지만, 정작 실무자들은 밀려드는 당장 업무를 처리하느라 새로운 툴을 학습할 물리적 시간이 부족합니다.
> 본 교재는 이러한 실무자들의 현실적인 페인 포인트(Pain Point)를 해결하기 위해 기획되었습니다.
> Calude Sonnet 4.6으로 생성하였음을 밝히며, 교재가 잘못된 정보를 담고 있을 수 있습니다. 문의 주시기 바랍니다.

> **"나만의 아이디어를 직접 코드로 구현해보고 싶지 않으신가요?"**
> 코딩을 배우고 싶다는 열정만 있다면 충분합니다. 본 교재는 기술적 진입장벽 때문에 망설였던 개인 학습자들을 위해 기획되었습니다.
> 최신 개발 생태계의 핵심인 **Google Antigravity 2.0**과 강력한 **IDE**의 도움을 받으면, 복잡한 코드를 일일이 타이핑하지 않아도 구조를 이해하고 제어할 수 있습니다. 가장 현대적이고, 가장 직관적인 방식으로 여러분의 첫 번째 프로그램을 완성해 보세요.

> **"나만의 24시간 AI 코딩 멘토를 만나보세요."**
> 혼자서 코딩을 독학할 때 가장 힘든 점은 "내가 제대로 짜고 있는 걸까?"라는 불안감과 막혔을 때 물어볼 사람이 없다는 외로움입니다.
> 본 교재는 **ChatGPT Codex를 나만의 전담 코딩 멘토로 최적화하여 활용하는 방법**을 다룹니다. 코드 한 줄 쓰기 두려운 입문자도 Codex의 강력한 자동 완성 및 최적화 기능을 발판 삼아, 가장 쉽고 빠르게 개발의 즐거움을 느낄 수 있도록 안내합니다.

> **코드 한 줄 쓰지 않고도 시작하는, AI 네이티브 개발의 신세계.**
> 프로그래밍을 배우고 싶지만, 복잡한 개발 환경과 낯선 문법 앞에서 길을 잃으셨나요?
> 본 교재는 차세대 AI 코드 편집기인 **Cursor(커서)**를 활용하여, 코딩 입문자가 가장 빠르고 직관적으로 결과물을 만들어낼 수 있도록 안내합니다. 코드 작성부터 디버깅, 리팩토링까지 AI와 유기적으로 협업하는 방법을 배웁니다. 복잡한 문법 암기는 Cursor에게 맡기고, 여러분은 오직 **'아이디어와 논리'**에만 집중하세요.

## 소개

이 저장소는 현재 주목받는 4가지 에이전틱 개발 도구(Claude Code·Google Antigravity 2.0 & IDE·ChatGPT Codex·Cursor)를 처음 접하는 학습자가 완전히 익힐 수 있도록 설계된 **총 61편의 한국어 교재**를 담고 있다.

단순한 사용 설명서가 아니다. 각 도구의 패러다임과 아키텍처를 이해하는 이론부터, 실제 풀스택 프로젝트(SvelteKit + NestJS + PostgreSQL 16 멀티 게시판)를 완성하는 실전까지 한 흐름으로 연결된다.

### 이 교재 시리즈의 특징

- **61편 완성**: Claude Code 15편 · Google Antigravity 2.0 16편 · ChatGPT Codex 15편 · Cursor 15편
- **일관된 예제 프로젝트**: 4개 시리즈 모두 동일한 멀티 게시판 허브를 기준 프로젝트로 사용하여 도구 간 비교가 가능하다
- **역할별 학습 경로**: 개발자·기획자·디자이너 각각에게 맞는 권장 학습 순서를 제공한다
- **편당 500줄 이상**: 이론 → 실전 예시 → 코드 → 실습 → 체크리스트 구성의 완성형 레퍼런스
- **도구 간 비교 관점**: 같은 개념(에이전트 규칙서, MCP, 멀티에이전트 등)을 4가지 도구의 관점에서 비교하여 학습한다

## 학습 경로

### 처음 시작하는 사람

에이전틱 개발이 처음이라면 **Claude Code 시리즈 01편**부터 시작한다. 에이전트 퍼스트 패러다임의 개념을 처음 배우기에 가장 적합한 입문 교재다.

```
Claude Code 01편 → 02편 → 03편 → ...
```

Claude Code 시리즈를 완주한 뒤, 비교 학습으로 다른 시리즈의 입문편(01편)을 읽으면 각 도구의 철학과 차이를 명확히 이해할 수 있다.

### 도구를 이미 쓰고 있는 개발자

사용 중인 도구의 시리즈로 바로 진입한다. 커리큘럼 정의서(00편)를 먼저 읽고 자신의 수준에 맞는 편부터 시작한다.

### 기획자·디자이너

각 시리즈의 커리큘럼 정의서에 명시된 **기획자·디자이너 핵심 경로**를 따른다. 코딩 지식 없이도 에이전트 친화적 기획서 작성법을 익힐 수 있다.

### 도구 비교 학습

동일한 주제(예: 에이전트 규칙서, MCP, 멀티에이전트)를 4개 시리즈에서 각각 어떻게 다루는지 비교하며 읽으면 깊이 있는 이해가 가능하다.

| 공통 주제 | Claude Code | Antigravity 2.0 | ChatGPT Codex | Cursor |
|---------|:-----------:|:---------------:|:-------------:|:------:|
| 에이전트 규칙서 | 03편 CLAUDE.md | 04편 GEMINI.md | 03편 AGENTS.md | 03편 Cursor Rules |

## 공통 예제 프로젝트

4개 시리즈 모두 동일한 예제 프로젝트를 기준으로 실습한다.

**멀티 게시판 허브 (Board Hub)**

하나의 플랫폼에서 8종의 게시판을 통합 관리하는 커뮤니티 서비스다.

| 게시판 유형 | 설명 |
|-------------|------|
| 일반 게시판 | 텍스트 중심 게시글, 좋아요·댓글·검색 |
| 갤러리 게시판 | 이미지 중심, 썸네일 그리드 |
| 동영상 게시판 | 동영상 임베드·업로드 |
| Q&A 게시판 | 질문·답변 형식, 채택 기능 |
| 공지 게시판 | 관리자 전용 작성, 상단 고정 |
| FAQ 게시판 | 아코디언 형식, 카테고리 분류 |
| 비공개 문의 | 1:1 문의, 작성자·관리자만 열람 |
| 자유 게시판 | 익명 허용, 신고 기능 |

**기술 스택**

```
프론트엔드:   SvelteKit 2.x (TypeScript) + TailwindCSS
백엔드:       NestJS 10.x (TypeScript) + JWT + Passport
데이터베이스: PostgreSQL 16 + Prisma v5 ORM
패키지 관리:  pnpm 8.x (모노레포 워크스페이스)
컨테이너:     Docker Compose
구조:         디커플드 모노레포 (apps/frontend + apps/backend)
```
