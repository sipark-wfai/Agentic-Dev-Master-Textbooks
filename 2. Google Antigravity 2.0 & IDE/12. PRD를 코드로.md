> **R6 수정**: agy agent wait --timeout 구문 주의 안내 정리. Proposal 카드 관련 명칭 → 변경사항 검토/수락으로 수정. 핵심 자율 구현 워크플로우는 공식 확인된 내용이므로 유지.

# 12. PRD를 코드로 — 자율 구현 워크플로우 완벽 가이드

> **학습 목표**
> - PRD에서 코드까지의 자율 구현 워크플로우를 이해한다
> - 마일스톤 분할 전략으로 대형 프로젝트를 안전하게 구현한다
> - agy agent run + agy agent wait 패턴을 CI/CD에 통합한다
> - 에이전트 결과물을 효과적으로 검토하고 수락한다

---

## 1. 자율 구현 워크플로우

PRD가 완성되면 에이전트에게 자율적으로 구현하도록 지시할 수 있다.

```
PRD (문서) → 에이전트 → 코드 (실제 파일)

자율 구현 과정:
1. PRD + GEMINI.md를 컨텍스트로 제공
2. 에이전트가 마일스톤을 자동으로 분할
3. 각 마일스톤별로 코드 생성
4. 개발자가 변경사항을 검토하고 수락/거부
5. 수락된 코드로 다음 마일스톤 진행
```

---

## 2. 마일스톤 분할 전략

대형 프로젝트를 한 번에 구현하려 하면 컨텍스트 고갈과 품질 저하가 발생한다. 마일스톤으로 분할해야 한다.

### 2.1 BoardHub 마일스톤 분할

```
마일스톤 1 — 기반 (약 30분)
  목표: Prisma 스키마 + 마이그레이션
  결과물: prisma/schema.prisma, migration 파일

마일스톤 2 — 인증 (약 45분)
  목표: 회원가입/로그인 API
  결과물: src/auth/, src/users/

마일스톤 3 — 게시판 (약 60분)
  목표: 8종 게시판 게시글 CRUD
  결과물: src/boards/, src/posts/

마일스톤 4 — 댓글/파일 (약 45분)
  목표: 댓글 + 파일 업로드
  결과물: src/comments/, src/files/

마일스톤 5 — 프론트엔드 (약 90분)
  목표: SvelteKit 프론트엔드
  결과물: apps/frontend/

마일스톤 6 — 통합/배포 (약 30분)
  목표: 통합 테스트 + Docker Compose
  결과물: docker-compose.yml, test/e2e/
```

## 3. 마일스톤 구현 패턴

### 3.1 마일스톤 1: Prisma 스키마

```bash
agy agent run "마일스톤 1을 구현해줘:
  BoardHub ERD를 기반으로 Prisma 스키마를 작성하고
  초기 마이그레이션을 생성해줘.
  소프트 딜리트(deletedAt), 복합 인덱스 포함"
  # --file docs/erd.md --file GEMINI.md

# 작업 완료 대기
agy agent wait --timeout 300
```

에이전트 작업 완료 후 IDE에서 변경사항을 검토하고 수락한다:
```
변경사항 검토:
- prisma/schema.prisma  (+120줄)  [Diff View] [수락] [거부]
- prisma/migrations/...  (+200줄) [Diff View] [수락] [거부]
```

### 3.2 마일스톤 2: 인증 모듈

```bash
agy agent run "마일스톤 2를 구현해줘:
  완성된 Prisma 스키마 기반으로 인증 시스템 구현:
  - POST /api/auth/register (회원가입)
  - POST /api/auth/login (JWT 발급)
  - POST /api/auth/logout (토큰 폐기)
  - POST /api/auth/refresh (토큰 갱신)
  GEMINI.md의 응답 형식 규칙 준수"
  # --file GEMINI.md --file prisma/schema.prisma

agy agent wait --timeout 600
```

### 3.3 마일스톤 완료 검증

각 마일스톤 완료 후 검증:

```bash
# 에이전트에게 검증 요청
agy agent run "마일스톤 2 완료 검증:
  1. POST /api/auth/register 동작 확인 (200 응답)
  2. POST /api/auth/login 동작 확인 (JWT 반환)
  3. 단위 테스트 커버리지 확인
  보고서를 MILESTONE_2_REPORT.md로 작성해줘"

agy agent wait --timeout 180
```

## 4. CI/CD 통합

```yaml
# .github/workflows/ai-implementation.yml
name: AI Implementation Pipeline

on:
  workflow_dispatch:
    inputs:
      milestone:
        description: 'Milestone number (1-6)'
        required: true

jobs:
  implement:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Antigravity CLI
        run: brew install --cask antigravity-cli
        
      - name: Configure API Key
        run: agy config set gemini.apiKey "${{ secrets.GEMINI_API_KEY }}"
        
      - name: Run Agent
        run: |
          agy agent run "마일스톤 ${{ inputs.milestone }} 구현" --non-interactive
          agy agent wait --timeout 1800
          
      - name: Commit Results
        run: |
          git add .
          git commit -m "feat: 마일스톤 ${{ inputs.milestone }} AI 구현"
          git push
```
