# 07. 에이전트 스킬(Skills) 완벽 가이드 — 에이전트의 손과 발을 확장하는 법

> **학습 목표**
> - MCP(눈·귀)와 Skills(손·발)의 명확한 차이를 이해한다
> - Skills 아키텍처와 온디맨드 로딩 원리를 파악한다
> - 실전 스킬(image-optimizer, video-thumbnailer, deploy-vercel)을 설치·활용한다
> - SKILL.md 작성법을 익혀 커스텀 스킬을 직접 만든다
> - 멀티 게시판 이미지 업로드에 image-optimizer 스킬을 적용한다

---

## 1. Skills의 정의 — MCP와의 핵심 차이

### 1.1 MCP vs Skills 비교

Antigravity 에코시스템에는 두 가지 확장 메커니즘이 있다.

| 구분 | MCP (눈·귀) | Skills (손·발) |
|------|-----------|--------------|
| 역할 | 외부 정보를 읽어오는 것 | 실제 작업을 수행하는 것 |
| 방향 | 읽기 중심 (Read) | 쓰기/실행 중심 (Write/Execute) |
| 예시 | DB 스키마 조회, Git 이력 읽기 | 이미지 변환, 파일 배포, 영상 처리 |
| 지속성 | 항상 활성화 | 필요할 때만 로딩 (온디맨드) |
| 런타임 | MCP 서버 프로세스 | 샌드박스 내 격리 실행 |
| 자원 사용 | 낮음 (상시 대기) | 높음 (작업 시에만) |

**MCP**: 에이전트가 "현재 DB에 어떤 테이블이 있는지 알아야 한다" → MCP로 조회
**Skills**: 에이전트가 "이 이미지를 WebP로 변환해야 한다" → image-optimizer 스킬 실행

### 1.2 Skills가 필요한 이유

에이전트가 이미지를 처리하려면:
1. Sharp, ImageMagick 같은 이미지 처리 라이브러리 필요
2. 이 라이브러리들은 컨텍스트 윈도우를 차지하면 안 됨
3. 필요할 때만 로딩하고, 사용 후 언로딩

이것이 Skills의 핵심 설계 원칙인 **"온디맨드 로딩"**이다. 이미지 처리 스킬은 갤러리 게시판 구현 시에만 로딩되고, 그 외에는 메모리에서 해제된다.

```
컨텍스트 블로트 방지:

방식 1 (스킬 없음):
  Gemini 컨텍스트 = 코드 + DB정보 + 이미지처리API + 동영상처리API + 배포API + ...
  → 컨텍스트 윈도우 낭비, 느려짐

방식 2 (스킬 있음):
  Gemini 컨텍스트 = 코드 + DB정보
  + [image-optimizer 스킬 온디맨드 로딩] ← 갤러리 게시판 작업 시에만
  → 컨텍스트 효율, 빠름
```

## 4. SKILL.md 파일 구조 및 작성법

모든 스킬은 SKILL.md 파일로 정의된다. 에이전트는 SKILL.md를 읽어 스킬의 사용법과 제한사항을 파악한다.

### 4.1 SKILL.md 기본 구조

```markdown
# [스킬 이름]

## 개요
스킬의 목적과 주요 기능을 간략히 설명

## 의존성
- npm 패키지 목록
- 시스템 의존성 (ffmpeg, imagemagick 등)

## 함수 명세

### [함수명](파라미터) → 반환값
**설명**: 함수가 하는 일
**파라미터**:
  - param1 (타입): 설명
  - param2 (타입): 설명
**반환**: 반환값 설명
**예시**: 사용 예시 코드

## 제한사항
- 파일 크기 제한
- 지원 포맷
- 처리 시간 제한

## 오류 코드
- ERROR_CODE: 설명 및 해결 방법
```

### 4.2 image-optimizer 스킬의 SKILL.md

```markdown
# image-optimizer v1.2.0

## 개요
이미지 파일을 WebP 포맷으로 변환하고, 다양한 크기의 썸네일을 생성하며,
EXIF 메타데이터를 추출한다. 갤러리 게시판의 이미지 처리에 특화되어 있다.

## 의존성
- sharp@0.33.0 (네이티브 이미지 처리)
- exifr@7.1.3 (EXIF 메타데이터 추출)

## 함수 명세

### convertToWebP(inputPath, options) → OutputResult
**설명**: JPEG, PNG, GIF를 WebP로 변환하여 파일 크기를 줄인다
**파라미터**:
  - inputPath (string): 입력 이미지 파일 경로
  - options.quality (number, 1-100): WebP 품질 (기본값: 80)
  - options.outputDir (string): 출력 디렉터리 (기본값: 입력 파일과 동일)
  - options.keepOriginal (boolean): 원본 파일 보존 여부 (기본값: true)
**반환**: { outputPath: string, originalSize: number, newSize: number, ratio: number }
**예시**:
  await skill.convertToWebP('/uploads/photo.jpg', { quality: 85, keepOriginal: false })
  → { outputPath: '/uploads/photo.webp', originalSize: 1240000, newSize: 287000, ratio: 0.23 }

### generateThumbnail(inputPath, sizes) → ThumbnailResult[]
**설명**: 다양한 크기의 썸네일을 생성한다
**파라미터**:
  - inputPath (string): 원본 이미지 파일 경로
  - sizes (Array): 썸네일 크기 배열
    - width (number): 너비 (픽셀)
    - height (number): 높이 (픽셀)
    - suffix (string): 파일명 접미사 (예: 'sm', 'md', 'lg')
**반환**: ThumbnailResult[] — 각 썸네일의 경로와 크기 정보
**예시**:
  await skill.generateThumbnail('/uploads/photo.webp', [
    { width: 150, height: 150, suffix: 'thumb' },
    { width: 640, height: 480, suffix: 'medium' },
    { width: 1280, height: 960, suffix: 'large' },
  ])

### extractMetadata(inputPath) → ImageMetadata
**설명**: 이미지의 EXIF 메타데이터(촬영 정보, GPS 등)를 추출한다
**반환**: { width, height, format, size, exif: { make, model, gps, ... } }

## 제한사항
- 지원 입력 포맷: JPEG, PNG, GIF, TIFF, BMP
- 최대 파일 크기: 50MB
- 최대 처리 시간: 30초/파일

## 오류 코드
- IMAGE_TOO_LARGE: 파일이 50MB 초과 → 서버에서 사전 검증 필요
- UNSUPPORTED_FORMAT: 지원하지 않는 포맷 → 업로드 전 포맷 검증
- SHARP_INIT_FAILED: Sharp 초기화 실패 → ag skill reinstall image-optimizer
```

## 5. 실전 스킬 활용 예시

### 5.1 image-optimizer: 갤러리 게시판 이미지 처리

```
/code "갤러리 게시판에서 이미지 업로드 시 다음을 처리하는 FilesService를 구현해줘:
       1. 업로드된 이미지를 WebP로 변환 (품질 85%)
       2. 세 가지 썸네일 생성 (150x150, 640x480, 1280x960)
       3. 원본 파일 삭제 (WebP만 보관)
       4. 처리 결과를 DB에 저장

       image-optimizer 스킬을 활용해줘"

에이전트가 생성한 코드:
```

```typescript
// src/files/files.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { ConfigService } from '@nestjs/config';

@Injectable()
export class FilesService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly config: ConfigService,
  ) {}

  /**
   * 갤러리 게시판 이미지 업로드 처리
   * image-optimizer 스킬을 사용하여 WebP 변환 및 썸네일 생성
   */
  async processGalleryImage(
    file: Express.Multer.File,
    postId: number,
    uploaderId: number,
  ) {
    const uploadDir = this.config.get<string>('UPLOAD_DIR', './uploads');
    const originalPath = file.path;

    // image-optimizer 스킬 호출
    // WebP 변환
    const webpResult = await skill.image_optimizer.convertToWebP(originalPath, {
      quality: 85,
      outputDir: uploadDir,
      keepOriginal: false,  // 원본 삭제
    });

    // 썸네일 생성
    const thumbnails = await skill.image_optimizer.generateThumbnail(
      webpResult.outputPath,
      [
        { width: 150, height: 150, suffix: 'thumb' },
        { width: 640, height: 480, suffix: 'medium' },
        { width: 1280, height: 960, suffix: 'large' },
      ]
    );

    // DB 저장
    const savedFile = await this.prisma.file.create({
      data: {
        postId,
        uploaderId,
        originalName: file.originalname,
        webpPath: webpResult.outputPath,
        thumbnailSmPath: thumbnails[0].outputPath,
        thumbnailMdPath: thumbnails[1].outputPath,
        thumbnailLgPath: thumbnails[2].outputPath,
        originalSize: file.size,
        webpSize: webpResult.newSize,
        compressionRatio: webpResult.ratio,
        mimeType: 'image/webp',
      },
    });

    return savedFile;
  }
}
```

```typescript
/**
 * 동영상 게시판 업로드 처리
 * video-thumbnailer 스킬로 썸네일 추출
 */
async processVideoPost(
  videoFile: Express.Multer.File,
  postId: number,
  uploaderId: number,
) {
  const videoPath = videoFile.path;

  // video-thumbnailer 스킬 호출
  const thumbnail = await skill.video_thumbnailer.extractFrame(videoPath, {
    timePosition: '00:00:03',  // 3초 지점에서 추출
    outputFormat: 'webp',
    width: 640,
    height: 360,
  });

  const videoDuration = await skill.video_thumbnailer.getDuration(videoPath);
  const videoMetadata = await skill.video_thumbnailer.getMetadata(videoPath);

  return await this.prisma.file.create({
    data: {
      postId,
      uploaderId,
      originalName: videoFile.originalname,
      videoPath: videoFile.path,
      thumbnailPath: thumbnail.outputPath,
      duration: videoDuration,
      resolution: `${videoMetadata.width}x${videoMetadata.height}`,
      codec: videoMetadata.codec,
      mimeType: videoFile.mimetype,
    },
  });
}
```

## 6. 커스텀 스킬 직접 만들기

BoardHub 프로젝트에 필요한 커스텀 스킬을 만들어보자. 게시글 내용에서 욕설을 필터링하는 `content-filter` 스킬이다.

### 6.1 스킬 디렉터리 구조

```
.agents/skills/content-filter/
├── SKILL.md          (스킬 명세)
├── package.json      (의존성)
├── index.js          (스킬 구현)
└── wordlist.txt      (금지어 목록)
```

### 6.2 SKILL.md 작성

```markdown
# content-filter v1.0.0

## 개요
게시글 제목과 내용에서 금지어를 감지하고 마스킹 처리한다.
BoardHub 커뮤니티 가이드라인 준수를 위한 내부 스킬.

## 함수 명세

### filterContent(text) → FilterResult
**설명**: 텍스트에서 금지어를 감지하여 마스킹 처리
**파라미터**:
  - text (string): 검사할 텍스트
**반환**: { filtered: string, detected: string[], passed: boolean }
**예시**:
  filterContent("안녕하세요 [금지어] 반갑습니다")
  → { filtered: "안녕하세요 ** 반갑습니다", detected: ["금지어"], passed: false }

### validatePost(title, content) → ValidationResult
**설명**: 게시글 제목과 내용을 검증
**반환**: { valid: boolean, issues: string[] }
```

### 6.3 index.js 구현

```javascript
// .agents/skills/content-filter/index.js
const fs = require('fs');
const path = require('path');

// 금지어 목록 로딩
const wordlistPath = path.join(__dirname, 'wordlist.txt');
const forbiddenWords = fs.readFileSync(wordlistPath, 'utf-8')
  .split('
')
  .filter(w => w.trim().length > 0);

/**
 * 텍스트에서 금지어를 감지하고 마스킹 처리
 */
function filterContent(text) {
  const detected = [];
  let filtered = text;

  for (const word of forbiddenWords) {
    if (filtered.includes(word)) {
      detected.push(word);
      filtered = filtered.replace(
        new RegExp(word, 'gi'),
        '*'.repeat(word.length)
      );
    }
  }

  return {
    filtered,
    detected,
    passed: detected.length === 0,
  };
}

/**
 * 게시글 검증 (제목 + 내용)
 */
function validatePost(title, content) {
  const titleResult = filterContent(title);
  const contentResult = filterContent(content);

  const issues = [];
  if (!titleResult.passed) {
    issues.push(`제목에 금지어 포함: ${titleResult.detected.join(', ')}`);
  }
  if (!contentResult.passed) {
    issues.push(`내용에 금지어 포함: ${contentResult.detected.join(', ')}`);
  }

  return {
    valid: issues.length === 0,
    filteredTitle: titleResult.filtered,
    filteredContent: contentResult.filtered,
    issues,
  };
}

module.exports = { filterContent, validatePost };
```


```
├── (설치됨) image-optimizer    ← 갤러리 게시판

```

```markdown
## 스킬 사용 규칙

@must 갤러리(GALLERY) 게시판 이미지 업로드 시 image-optimizer 스킬 사용
@must 동영상(VIDEO) 게시판 업로드 시 video-thumbnailer 스킬 사용
@must 모든 게시글 작성 시 content-filter 스킬로 금지어 검사
@prefer 배포 전 빌드 성공 확인 후 deploy-vercel 스킬 실행
```
