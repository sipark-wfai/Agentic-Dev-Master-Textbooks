# 06. MCP(Model Context Protocol) 완벽 가이드 — 에이전트의 눈과 귀를 연결하는 법

> **학습 목표**
> - MCP가 없을 때 발생하는 환각(Hallucination) 문제를 이해한다
> - MCP 아키텍처와 데이터 흐름을 파악한다
> - 핵심 MCP 서버(PostgreSQL, Git, 파일 시스템)를 설정하고 활용한다
> - 멀티 게시판 PostgreSQL 데이터베이스를 MCP로 연동한다
> - MCP 서버 디버깅 방법을 익힌다

---

## 1. MCP가 없을 때의 문제 — 환각(Hallucination)

에이전트에게 MCP 없이 코드를 생성하면 어떤 문제가 발생하는지 보자:

```
개발자: "users 테이블에서 이메일로 사용자를 찾는 쿼리를 작성해줘"

에이전트 (MCP 없음):
async findByEmail(email: string) {
  return await this.prisma.user.findUnique({
    where: { email },
    select: {
      id: true,
      email: true,
      username: true,    ← 실제 스키마에 없는 필드 (환각)
      avatar: true,      ← 실제 스키마에 없는 필드 (환각)
    }
  });
}

실제 User 모델:
model User {
  id        Int    @id @default(autoincrement())
  email     String @unique
  nickname  String    ← 'username'이 아닌 'nickname'
  profile   String?   ← 'avatar'가 아닌 'profile'
  createdAt DateTime
}
```

에이전트는 실제 DB 스키마를 모르기 때문에 추측으로 코드를 작성한다. MCP를 통해 에이전트에게 실제 데이터 소스에 접근하는 "눈과 귀"를 제공하면 이 문제가 해결된다.

---

## 2. MCP 아키텍처

```
에이전트
    │
    ├── postgres-mcp → PostgreSQL DB 연결
    │                  (스키마 조회, 데이터 읽기)
    │
    ├── filesystem-mcp → 로컬 파일 시스템
    │                    (파일 읽기, 구조 탐색)
    │
    ├── git-mcp → Git 저장소
    │             (커밋 이력, 브랜치, 변경사항)
    │
    └── 웹 검색 MCP → 실시간 웹 정보
                      (최신 라이브러리, 문서)
```

### 2.1 MCP Lazy-Loading 최적화

Antigravity는 MCP lazy-loading을 지원한다. MCP 서버는 에이전트가 실제로 해당 도구를 사용할 때만 활성화되어 불필요한 리소스 낭비를 막는다.

## 3. MCP 설정 파일

### 3.1 공식 설정 파일 위치

```
~/.gemini/config/mcp_config.json
```

이 경로가 공식 확인된 MCP 설정 파일 위치다.

### 3.2 설정 예시

```json
{
  "mcpServers": {
    "postgres-mcp": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://boardhub_user:password@localhost:5432/boardhub_db"
      }
    },
    "filesystem-mcp": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem",
               "/Users/developer/projects/boardhub"]
    },
    "git-mcp": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-git",
               "--repository", "/Users/developer/projects/boardhub"]
    }
  }
}
```

## 4. 핵심 MCP 서버 설정 및 활용

### 4.1 PostgreSQL MCP (postgres-mcp)

가장 중요한 MCP 서버다. 에이전트가 실제 DB 스키마를 읽어 환각 없는 코드를 생성한다.

```bash
# MCP 서버 상태 확인
agy mcp list
# → [active] postgres-mcp
# → [active] filesystem-mcp
# → [active] git-mcp

# MCP 서버 연결 테스트
agy mcp status postgres-mcp

# MCP 서버 로그 확인
agy mcp logs postgres-mcp --tail 20
```

**활용 예시:**
```
/ask "현재 posts 테이블의 실제 스키마를 확인해줘"

에이전트 (MCP 있음):
postgres-mcp를 통해 실제 스키마를 확인합니다...

현재 posts 테이블:
- id: Int (PK, autoincrement)
- title: String (최대 200자)
- content: String
- boardId: Int (FK → boards.id)
- authorId: Int? (nullable - 익명 허용)
- deletedAt: DateTime? (소프트 딜리트)
```

### 4.2 파일 시스템 MCP (filesystem-mcp)

프로젝트 파일 구조를 에이전트가 자율적으로 탐색할 수 있게 한다.

```
/ask "현재 프로젝트 구조를 파악하고 누락된 모듈을 알려줘"

에이전트:
filesystem-mcp로 프로젝트 구조를 분석합니다...

발견된 모듈:
✅ src/auth/
✅ src/users/
✅ src/boards/
❌ src/posts/ → 누락 (구현 필요)
❌ src/comments/ → 누락 (구현 필요)
```

### 4.3 Git MCP (git-mcp)

```
/ask "지난 주에 authentication 모듈에서 어떤 변경이 있었나요?"

에이전트:
git-mcp로 커밋 이력을 확인합니다...

지난 7일 authentication 모듈 변경사항:
1. 2026-06-01: feat: JWT refresh token 로직 추가 (개발자A)
2. 2026-06-03: fix: 토큰 만료 처리 버그 수정 (개발자B)
3. 2026-06-05: test: JWT 검증 단위 테스트 추가 (개발자A)
```

## 5. MCP 환경별 설정 관리

### 5.1 프로젝트 수준 설정

```json
// {프로젝트루트}/.gemini/mcp_config.json
{
  "mcpServers": {
    "postgres-mcp": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "${DATABASE_URL}"
      }
    }
  }
}
```

프로젝트 루트의 `.gemini/mcp_config.json`은 Git으로 팀과 공유할 수 있다. 단, 실제 DATABASE_URL 같은 비밀 값은 환경변수로 분리한다.

### 5.2 팀 공유 설정

```bash
# 팀 공유 MCP 설정 (Git 커밋)
.gemini/mcp_config.json     # 서버 목록과 구조

# 개인 설정 (.gitignore에 추가)
.env                        # 실제 연결 정보
```

## 6. MCP 서버 트러블슈팅

### 6.1 MCP 연결 실패

```bash
# 오류 로그 확인
agy mcp logs postgres-mcp --tail 20

# PostgreSQL 실행 확인
docker ps | grep postgres

# 연결 직접 테스트
psql "postgresql://boardhub_user:password@localhost:5432/boardhub_db" -c "SELECT 1"

# MCP 서버 재시작
agy mcp restart postgres-mcp
```

### 6.2 MCP 서버 추가 후 에이전트 인식 안 됨

```bash
# MCP 설정 재로드 (데몬 재시작)
agy status
# Desktop App 재시작이 필요할 수 있음

agy mcp list
# 새로 추가된 서버가 목록에 표시되는지 확인
```
