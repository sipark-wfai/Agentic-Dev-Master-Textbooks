# 07. 에이전트 스킬(Skills) 완벽 가이드 — 에이전트의 손과 발을 확장하는 법

> **학습 목표**
> - MCP(눈·귀)와 Skills(손·발)의 명확한 차이를 이해한다
> - Skills 아키텍처와 온디맨드 로딩 원리를 파악한다
> - 스킬 설치 및 관리 명령어를 익힌다
> - SKILL.md 작성법을 익혀 커스텀 스킬을 직접 만든다
> - 멀티 게시판 이미지 처리에 스킬을 활용한다

---

## 1. Skills의 정의 — MCP와의 핵심 차이

### 1.1 MCP vs Skills 비교

| 구분 | MCP (눈·귀) | Skills (손·발) |
|------|-----------|--------------|
| 역할 | 외부 정보를 읽어오는 것 | 실제 작업을 수행하는 것 |
| 방향 | 읽기 중심 (Read) | 쓰기/실행 중심 (Write/Execute) |
| 예시 | DB 스키마 조회, Git 이력 읽기 | 이미지 변환, 파일 배포, 영상 처리 |
| 지속성 | 항상 활성화 | 필요할 때만 로딩 (온디맨드) |
| 자원 사용 | 낮음 (상시 대기) | 높음 (작업 시에만) |

**MCP**: "현재 DB에 어떤 테이블이 있는지 알아야 한다" → MCP로 조회
**Skills**: "이 이미지를 WebP로 변환해야 한다" → image 처리 스킬 실행

### 1.2 온디맨드 로딩 원리

```
컨텍스트 최적화:

스킬 없음:
  Gemini 컨텍스트 = 코드 + DB정보 + 이미지처리API + 동영상처리API + 배포API + ...
  → 컨텍스트 윈도우 낭비

스킬 사용:
  Gemini 컨텍스트 = 코드 + DB정보
  + [이미지 처리 스킬 온디맨드 로딩] ← 갤러리 게시판 작업 시에만
  → 컨텍스트 효율, 비용 절감
```

## 2. 스킬 관리 명령어

```bash
# 설치된 스킬 목록 확인
agy skill list
# → [installed] image-optimizer v1.2.0
# → [installed] video-thumbnailer v0.9.1

# 스킬 설치
agy skill install image-optimizer
agy skill install video-thumbnailer

# 스킬 제거
agy skill remove image-optimizer

# 스킬 테스트
agy skill test image-optimizer

# 스킬 업데이트
agy skill update image-optimizer
```

## 3. 실전 스킬 활용

### 3.1 이미지 처리 스킬 (갤러리 게시판)

갤러리 게시판에서 업로드된 이미지를 자동으로 최적화한다:

```bash
# 이미지 처리 스킬 설치
agy skill install image-optimizer

# 에이전트에게 갤러리 처리 구현 지시
/code "갤러리 게시판 이미지 업로드 시
  1. WebP 변환 (품질 85%)
  2. 썸네일 생성 (320x200)
  3. 원본 저장
  image-optimizer 스킬을 사용해줘"
```

### 3.2 동영상 처리 스킬 (동영상 게시판)

```bash
# 동영상 처리 스킬 설치
agy skill install video-thumbnailer

/code "동영상 게시판 업로드 시
  1. 동영상에서 1초 지점 썸네일 추출
  2. 썸네일을 WebP 320x180으로 저장
  video-thumbnailer 스킬을 사용해줘"
```

> **참고**: `image-optimizer`, `video-thumbnailer` 같은 스킬명은 공식 스킬 마켓플레이스의 정확한 ID와 다를 수 있다. 실제 설치 전 `agy skill search [키워드]`로 정확한 스킬명을 확인하라.

## 4. 커스텀 스킬 만들기 — SKILL.md 작성법

스킬은 `SKILL.md` + 구현 코드로 구성된다.

### 4.1 SKILL.md 기본 구조

```markdown
# 스킬명 (예: pdf-generator)

## 설명
PDF를 생성하는 스킬. HTML/Markdown을 PDF로 변환한다.

## 사용 가능한 도구

### generate_pdf
HTML 또는 Markdown 콘텐츠를 PDF 파일로 변환한다.

**파라미터:**
- `content` (string, 필수): HTML 또는 Markdown 텍스트
- `outputPath` (string, 필수): 저장할 파일 경로
- `format` (string, 선택): 'A4' | 'Letter' (기본값: 'A4')

**반환값:**
- `filePath` (string): 생성된 PDF 파일의 절대 경로
- `fileSize` (number): 파일 크기 (bytes)

**예시:**
에이전트가 "API 문서를 PDF로 내보내줘"라고 요청받았을 때 이 도구를 사용한다.
```

### 4.2 스킬 구현 파일 구조

```
my-pdf-generator/
├── SKILL.md          # 스킬 설명 (에이전트가 읽음)
├── package.json      # Node.js 의존성
├── src/
│   └── index.ts      # 스킬 구현
└── README.md         # 개발자용 문서
```

### 4.3 스킬 설치

```bash
# 로컬 스킬 설치
agy skill install ./my-pdf-generator

# 설치 확인
agy skill list
# → [installed] my-pdf-generator v1.0.0

# 동작 테스트
agy skill test my-pdf-generator
```

## 5. 스킬 트러블슈팅

### 5.1 스킬 로드 실패

```bash
agy skill list
# → [error] image-optimizer: Failed to load

# 재설치
agy skill remove image-optimizer
agy skill install image-optimizer

# 스킬 로그 확인
agy logs --filter skill
```

### 5.2 스킬 실행 중 의존성 오류

```bash
# 스킬 디렉터리에서 의존성 재설치
# (스킬은 샌드박스 내에서 격리 실행됨)
agy skill test image-optimizer --verbose
```
