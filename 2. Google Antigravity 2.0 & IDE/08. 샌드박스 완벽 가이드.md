# 08. 샌드박스 완벽 가이드 — 안전한 격리 실행 환경의 모든 것

> **학습 목표**
> - Secure Sandbox의 필요성과 작동 원리를 이해한다
> - macOS(sandbox-exec)와 Linux(nsjail) 격리 기술의 차이를 파악한다
> - 샌드박스 활성화 및 설정 방법을 익힌다
> - 파일 시스템 격리와 네트워크 격리를 설정한다
> - 샌드박스 관련 오류를 해결할 수 있다

---

## 1. 샌드박스의 필요성

에이전트가 격리 없이 직접 로컬 파일 시스템과 시스템 명령에 접근하면 심각한 위험이 있다:

**위험 시나리오 1: 실수로 인한 파일 삭제**
```bash
# 에이전트가 node_modules 정리를 시도하다가 경로 오해
rm -rf /Users/developer/projects/  # 전체 프로젝트 삭제 (복구 불가)
```

**위험 시나리오 2: 비밀 파일 노출**
```bash
# 에이전트가 디버그 로그에 .env 내용 포함 후 Git push
cat .env >> debug.log
git add debug.log && git commit -m "debug" && git push
# .env 내용이 GitHub에 공개
```

**위험 시나리오 3: 시스템 명령 오용**
```bash
# 포트 확인 중 다른 서비스 종료
kill -9 $(lsof -t -i:3000)  # 중요한 다른 서비스까지 종료
```

Secure Sandbox는 에이전트의 모든 작업을 OS 네이티브 격리 기술로 보호된 환경에서 실행한다.

---

## 2. Antigravity 샌드박스 기술

Antigravity는 OS별로 다른 격리 기술을 사용한다 (공식 확인):

| OS | 격리 기술 | 특징 |
|----|---------|------|
| macOS | `sandbox-exec` | macOS 네이티브 샌드박스 프로파일 기반 |
| Linux | `nsjail` | 네임스페이스 기반 경량 격리 |

> **중요**: `sandbox-exec`(macOS)와 `nsjail`(Linux) 사용은 공식 문서에서 확인된 정보다.

### 2.1 격리 범위

```
샌드박스 격리 범위:
  ✅ 파일 시스템: 지정된 작업 디렉터리만 접근 가능
  ✅ 네트워크: 허용된 도메인만 접근 가능
  ✅ 프로세스: 호스트 프로세스에 접근 불가
  ✅ 환경변수: 민감한 호스트 환경변수 차단
```

---

## 3. 샌드박스 활성화 방법

### 3.1 설정 파일에서 활성화

```json
// ~/.gemini/config.json
{
  "sandbox": {
    "enabled": true,
    "maxMemoryMB": 4096,
    "maxCpuMs": 120000,
    "networkPolicy": {
      "allowedDomains": [
        "registry.npmjs.org",
        "pypi.org",
        "pkg.go.dev"
      ]
    }
  }
}
```

### 3.2 CLI에서 샌드박스 플래그 사용

공식 방식은 `--sandbox` 플래그를 사용하는 것이다:

```bash
# 샌드박스 모드로 에이전트 실행
agy agent run "posts 모듈 구현" --sandbox

# 샌드박스 상태 확인
agy status
# → Sandbox: ✅ Ready (macOS: sandbox-exec)
```

> **참고**: `agy sandbox start/stop/reset` 등의 하위명령 패턴은 공식 문서에서 확인되지 않았다. 공식 방식은 `--sandbox` 플래그 또는 설정 파일의 `sandbox.enabled: true`다.

## 4. 샌드박스 설정 상세

### 4.1 파일 시스템 접근 제어

```json
{
  "sandbox": {
    "enabled": true,
    "fileSystem": {
      "workspaceDir": "/Users/developer/projects/boardhub",
      "allowedPaths": [
        "/Users/developer/projects/boardhub",
        "/tmp/antigravity-sandbox"
      ],
      "deniedPaths": [
        "/Users/developer/.ssh",
        "/Users/developer/.aws",
        "/etc",
        "/usr/bin"
      ]
    }
  }
}
```

### 4.2 네트워크 정책

```json
{
  "sandbox": {
    "networkPolicy": {
      "allowedDomains": [
        "registry.npmjs.org",
        "pypi.org",
        "pkg.go.dev",
        "deno.land"
      ],
      "allowLocalhost": true,
      "denyAll": false
    }
  }
}
```

### 4.3 리소스 제한

```json
{
  "sandbox": {
    "maxMemoryMB": 4096,
    "maxCpuMs": 120000,
    "timeoutSeconds": 300,
    "maxFileSize": "100MB"
  }
}
```
