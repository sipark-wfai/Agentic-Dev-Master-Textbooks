## 2. 20가지 오류 시나리오 해결 가이드

### 오류 1: Gemini API 키 인증 실패

```bash
# 증상
agy status → Gemini: Error: 401 Unauthorized

# 해결
agy config set gemini.apiKey "AIzaSy_새로운키..."

```

**예방**: 월별 사용량 알림 설정, API 키 정기 교체

---

### 오류 2: Desktop App 데몬 시작 실패

```bash
# 증상
agy status → Daemon: Error: Connection refused

# 해결: 포트 점유 프로세스 확인 및 종료
lsof -i :7432
kill -9 $(lsof -t -i:7432)

# Desktop App 재시작
# (메뉴바 Antigravity 아이콘 → Quit → 재실행)

# 로그로 원인 확인
cat ~/.gemini/antigravity-cli/log/cli-*.log | tail -30
```

> **참고**: `agy daemon start/restart/stop` 같은 하위명령 패턴은 공식 문서에서 확인되지 않았다. Antigravity 2.0은 Desktop App 통합 구조이므로 Desktop App을 통해 데몬을 관리한다.

---

## 마무리 — 에이전트 시대의 개발자로

이 시리즈를 완주한 당신은 이제 단순히 "코드를 작성하는 개발자"가 아니라, **"에이전트를 설계하고 제어하는 에이전트 엔지니어"**다.

에이전트 퍼스트 시대에서 경쟁력은:
- 더 빠르게 타이핑하는 것이 아니라
- 더 좋은 지시문(GEMINI.md + 슬래시 커맨드)을 작성하는 것
- 더 안전한 하네스를 설계하는 것
- 에이전트의 결과물을 더 정확하게 검토하는 것

Google Antigravity 2.0은 계속 진화한다. 하지만 이 시리즈에서 익힌 **에이전트 협업의 원칙**은 어떤 플랫폼에서도 적용된다.

이제 당신의 다음 프로젝트를 에이전트와 함께 시작하라.
