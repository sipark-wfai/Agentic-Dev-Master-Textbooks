## 2. macOS 설치 가이드

### 2.1 Desktop App 설치

**Step 1**: 공식 사이트에서 Desktop App 다운로드

```
URL: https://antigravity.google
파일명: Antigravity-2.0-Desktop-arm64.dmg  (Apple Silicon)
        Antigravity-2.0-Desktop-x64.dmg    (Intel Mac)
파일 크기: 약 420MB
```

**Step 2**: DMG 파일을 열고 Applications 폴더로 드래그한다

**Step 3**: Gatekeeper 보안 설정 해제 (필요 시)

```bash
xattr -d com.apple.quarantine /Applications/Antigravity.app
```

**Step 4**: 처음 실행

```
초기 실행 시 다음 단계가 자동으로 진행됨:
1. 로컬 에이전트 데몬 설치
2. 샌드박스 환경 초기화 (sandbox-exec 기반, macOS 공식 격리 기술)
3. MCP 서버 기본 패키지 설치
소요 시간: 약 3~8분
```

**Step 5**: 메뉴바에 Antigravity 아이콘(▲) 확인

### 2.2 IDE 설치 (macOS)

```
URL: https://ai.google.dev/antigravity/ide
파일명: Antigravity-IDE-darwin-arm64.dmg  (Apple Silicon)
        Antigravity-IDE-darwin-x64.dmg    (Intel Mac)
```

### 2.3 CLI 설치 (macOS)

```bash
# Homebrew Cask 사용 (공식 권장)
brew install --cask antigravity-cli

# 설치 확인
agy --version
# → Antigravity CLI v2.0.x (darwin/arm64)

# 지원 모델 목록 확인 (v1.0.5+)
agy models
```

## 3. Windows 설치 가이드

```bash
source ~/.bashrc
nvm install 22

```

## 4. Gemini API 키 발급 및 설정

### 4.1 Gemini API 키 발급

```
URL: https://aistudio.google.com
→ 'Get API key' → 'Create API key'
→ AIza...로 시작하는 39자리 문자열 생성
```

⚠ **주의**: API 키는 Git 저장소에 절대 커밋하지 말 것.

### 4.2 Desktop App에 API 키 설정

**방법 1**: Desktop App UI

```
메뉴바 Antigravity 아이콘 → Settings... → API Keys → Gemini API Key 입력 → Test Connection → Save
```

**방법 2**: 설정 파일 직접 편집

```bash
# macOS
nano ~/.gemini/config.json
```

```json
{
  "gemini": {
    "apiKey": "AIzaSy...",
    "model": "gemini-3.5-flash",
    "maxTokens": 200000
  },
  "sandbox": {
    "enabled": true,
    "maxMemoryMB": 4096,
    "maxCpuMs": 60000
  }
}
```

**방법 3**: 환경 변수

```bash
# ~/.zshrc 또는 ~/.bashrc에 추가
export GEMINI_API_KEY="AIzaSy..."
```

### 4.3 API 키 연결 확인


## 5. Desktop App과 IDE 연동 설정

Desktop App과 IDE는 gRPC를 통해 통신한다. 기본적으로 자동 연결된다.

### 5.1 연동 상태 확인

IDE 하단 상태바에서:
```
● Antigravity Daemon: Connected    ← 초록색: 정상
● Antigravity Daemon: Connecting   ← 노란색: 연결 중
● Antigravity Daemon: Disconnected ← 빨간색: 연결 실패
```

연결 실패 시 Desktop App 재시작을 시도한다:
```bash
# macOS에서 데몬 프로세스 재시작
pkill -f antigravity-daemon
# 이후 Desktop App 재실행
```

## 7. 자주 겪는 초기 오류 5가지

### 오류 1: 'Cannot connect to Docker daemon'

**원인**: Docker Desktop 미실행

```bash
open /Applications/Docker.app
docker ps  # 정상이면 agy status 재확인
```

### 오류 2: 'Gemini API key invalid or expired'

```bash
agy config set gemini.apiKey "AIzaSy..."
agy status
```

### 오류 3: Port already in use

```bash
# macOS/Linux
lsof -i :7432
kill -9 $(lsof -t -i:7432)
# 이후 Desktop App 재시작
```

### 오류 4: 'WSL2 kernel not found' (Windows)

```powershell
wsl --update
wsl --set-default-version 2
wsl --shutdown
# Docker Desktop 재시작
```

### 오류 5: Sandbox 초기화 실패

```bash
# Docker 실행 확인
docker ps

# 디스크 공간 확인
df -h
```

## 8. 첫 번째 Hello World 실습

### 8.1 프로젝트 준비

```bash
mkdir ~/boardhub-test
cd ~/boardhub-test
git init

# GEMINI.md 생성 (일반 Markdown 규칙 방식)
cat > GEMINI.md << 'EOF'
# BoardHub 테스트 프로젝트

## 필수 규칙
- 한국어로 주석을 작성한다
- TypeScript를 사용한다
- 함수는 단일 책임 원칙을 따른다
EOF

echo '프로젝트 준비 완료'
```

### 8.2 첫 번째 에이전트 실행

```bash
agy agent run "TypeScript로 간단한 hello.ts 파일을 만들어줘.
  인사말을 받아서 콘솔에 출력하는 greet 함수를 포함하고,
  main 함수에서 '안녕하세요, Antigravity!'를 출력해"

agy agent list
# → [running] agent-abc123: TypeScript로 간단한 hello.ts...

agy agent wait agent-abc123
```

### 8.3 IDE에서 변경사항 검토

에이전트 작업 완료 후 IDE의 에이전트 패널에서 생성된 파일을 확인하고 검토한다.

### 8.4 첫 번째 IDE 채팅 사용

```
/ask "이 hello.ts 파일에 테스트를 추가하려면 어떤 프레임워크를 사용하는 게 좋을까?"

/test "hello.ts의 greet 함수에 대한 단위 테스트를 Vitest로 작성해"
```
