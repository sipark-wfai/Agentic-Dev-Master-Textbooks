### 1.2 게시판 타입별 구현 가이드 문서 추가

에이전트가 8가지 게시판 타입을 올바르게 처리하도록 별도 문서를 추가한다:

```markdown
# docs/api/board-types.md

## 게시판 타입별 구현 명세

### GENERAL (일반 게시판)
- 파일 첨부: 선택 (제한 없음)
- 특수 로직: 없음
- 접근 제어: 인증 사용자 전체

### GALLERY (갤러리 게시판)
- 파일 첨부: 이미지 1~10개 필수 (JPEG, PNG, GIF, WebP, max 5MB)
- 특수 로직:
  - image-optimizer 스킬로 WebP 변환 (quality: 85)
  - 썸네일 3종 생성 (150x150, 640x480, 1280x960)
- 목록 조회: thumbnailSmPath 포함

### VIDEO (동영상 게시판)
- 파일 첨부: 동영상 1개 필수 (MP4, MOV, max 100MB)
- 특수 로직:
  - video-thumbnailer 스킬로 썸네일 추출 (3초 지점)
- 목록 조회: thumbnailPath, duration 포함

### QNA (Q&A 게시판)
- 파일 첨부: 선택
- 추가 필드: isAnswered, acceptedAnswerId
- 특수 로직:
  - 답변 채택: POST /api/posts/:id/accept-answer { answerId }
  - 작성자만 답변 채택 가능

### NOTICE (공지 게시판)
- 파일 첨부: 선택
- 접근 제어: 작성은 MODERATOR 이상만 가능
- 특수 로직: isPinned 지원 (관리자가 상단 고정 가능)

### FAQ (FAQ 게시판)
- 파일 첨부: 선택
- 특수 로직: category 필드 필수 (Board.settings에서 카테고리 목록 관리)

### PRIVATE (비공개 문의)
- 파일 첨부: 선택
- 접근 제어:
  - 목록 조회: 본인 글만 표시 (Admin은 전체)
  - 상세 조회: 작성자 또는 Admin만

### FREE (자유 게시판)
- 파일 첨부: 선택
- 특수 로직: isAnonymous 허용 (authorId = null)
- 목록/상세: isAnonymous=true면 작성자 정보 숨김
```

### 3.2 생성된 BoardsController 예시

```typescript
// src/boards/boards.controller.ts

import {
  Controller, Get, Post, Patch, Delete,
  Param, Body, Query, UseGuards, ParseIntPipe
} from '@nestjs/common';
import {
  ApiTags, ApiOperation, ApiResponse, ApiBearerAuth
} from '@nestjs/swagger';
import { BoardsService } from './boards.service';
import { CreateBoardDto } from './dto/create-board.dto';
import { UpdateBoardDto } from './dto/update-board.dto';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { RolesGuard } from '../common/guards/roles.guard';
import { Roles } from '../common/decorators/roles.decorator';
import { PaginationQueryDto } from '../common/dto/pagination-query.dto';

@ApiTags('boards')
@Controller('api/boards')
export class BoardsController {
  constructor(private readonly boardsService: BoardsService) {}

  /**
   * 게시판 목록 조회
   * 인증 불필요 — 모든 사용자 접근 가능
   */
  @Get()
  @ApiOperation({ summary: '게시판 목록 조회' })
  @ApiResponse({ status: 200, description: '조회 성공' })
  async findAll(@Query() query: PaginationQueryDto) {
    const { data, meta } = await this.boardsService.findAll(query);
    return { success: true, data, meta };
  }

  /**
   * 게시판 상세 조회
   */
  @Get(':id')
  @ApiOperation({ summary: '게시판 상세 조회' })
  async findOne(@Param('id', ParseIntPipe) id: number) {
    const data = await this.boardsService.findOne(id);
    return { success: true, data };
  }

  /**
   * 게시판 생성 — ADMIN 전용
   */
  @Post()
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('ADMIN')
  @ApiBearerAuth()
  @ApiOperation({ summary: '게시판 생성 (Admin)' })
  @ApiResponse({ status: 201, description: '생성 성공' })
  @ApiResponse({ status: 403, description: '권한 없음' })
  async create(@Body() createBoardDto: CreateBoardDto) {
    const data = await this.boardsService.create(createBoardDto);
    return { success: true, data };
  }

  /**
   * 게시판 수정 — ADMIN 전용
   */
  @Patch(':id')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('ADMIN')
  @ApiBearerAuth()
  async update(
    @Param('id', ParseIntPipe) id: number,
    @Body() updateBoardDto: UpdateBoardDto,
  ) {
    const data = await this.boardsService.update(id, updateBoardDto);
    return { success: true, data };
  }

  /**
   * 게시판 비활성화 — ADMIN 전용 (소프트)
   */
  @Delete(':id')
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles('ADMIN')
  @ApiBearerAuth()
  async remove(@Param('id', ParseIntPipe) id: number) {
    await this.boardsService.remove(id);
    return { success: true, data: null };
  }
}
```

  private readonly logger = new Logger(PrismaService.name);
