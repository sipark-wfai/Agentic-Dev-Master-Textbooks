## 1. 트러블슈팅 진단 프레임워크

문제가 발생했을 때 무작정 해결하려 하지 말고, 먼저 문제를 분류한다.

### 1.1 오류 유형 분류

```
Antigravity 오류 유형:

Level 1 — 환경 문제 (인프라)
  - Daemon 시작 실패
  - Sandbox 초기화 실패
  - API 키 인증 실패
  해결: 재시작, 설정 재확인

Level 2 — 연동 문제 (MCP/Skills)
  - MCP 서버 연결 실패
  - 스킬 실행 오류
  - IDE-Daemon 연결 끊김
  해결: 서버 재시작, 설정 재확인

Level 3 — 에이전트 동작 문제
  - 컨텍스트 윈도우 고갈
  - 에이전트 무한 루프
  - 환각 코드 생성
  - Proposal 카드 대량 누적
  해결: /compact, 재시작, MCP 보강

Level 4 — 코드 품질 문제
  - TypeScript 타입 오류 누적
  - Prisma 마이그레이션 충돌
  - 빌드 실패
  - 테스트 실패
  해결: 에이전트 자동 수정, 수동 수정

Level 5 — 프로젝트 관리 문제
  - 비용 폭발
  - 병렬 에이전트 충돌
  - Timemachine 롤백 실패
  해결: 하네스 재설정, 타임머신 복구
```

### 1.2 빠른 진단 명령어

```bash
# 전체 시스템 상태 확인
agy status --verbose

# 최근 오류 로그 확인
agy logs --level error --tail 50

# 에이전트 실행 이력 확인
agy agent list --all --limit 20

# MCP 서버 상태 확인
agy mcp list

# 비용 현황 확인
agy cost summary
```

### 오류 1: Gemini API 키 인증 실패

**증상**:
```
agy status → Gemini: Error: 401 Unauthorized
IDE: "API key is invalid or has been revoked"
```

**원인**: API 키 오타, 만료, 결제 계정 미설정, 사용량 한도 초과

**해결**:
```bash
# 1. Google AI Studio에서 API 키 상태 확인
# → https://aistudio.google.com/apikey

# 2. 새 API 키 생성 후 재설정
agy config set gemini.apiKey "AIzaSy_새로운키..."

# 3. 연결 테스트
agy status

# 4. 결제 한도 초과 시 Google Cloud Console에서 확인
```

**예방**: 월별 사용량 알림 설정, API 키를 정기적으로 교체

### 오류 2: Desktop App 데몬 시작 실패

**증상**:
```
Desktop App 실행 시 "Daemon failed to start"
agy status → Daemon: Error: Connection refused
```

**원인**: 포트 충돌(7432), 이전 데몬 좀비 프로세스, 권한 문제

**해결**:
```bash
# 포트 점유 프로세스 확인 및 종료
lsof -i :7432
kill -9 $(lsof -t -i:7432)

# 데몬 재시작
agy daemon start

# 로그로 정확한 원인 확인
agy daemon logs --tail 30
```

```
agy proposal reject --filter "testsPassed=false"
```

### 3.2 마일스톤 관리 루틴

```bash
# 마일스톤 완료 체크

              1. /auth/register, /auth/login 엔드포인트 동작 확인
              2. JWT 토큰이 httpOnly 쿠키로 설정되는지 확인
              3. 단위 테스트 커버리지 90% 확인
              보고서를 MILESTONE_2_REPORT.md로 작성해줘"

# 완료 후 Git 커밋
git add .
git commit -m "feat: 마일스톤 2 완료 - 인증 모듈 구현"

# Timemachine 스냅샷 확인
agy timemachine list --limit 5
```

## 마무리 — 에이전트 시대의 개발자로

이 시리즈를 완주한 당신은 이제 단순히 "코드를 작성하는 개발자"가 아니라, **"에이전트를 설계하고 제어하는 에이전트 엔지니어"**다.

에이전트 퍼스트 시대에서 경쟁력은:
- 더 빠르게 타이핑하는 것이 아니라
- 더 좋은 지시문을 작성하는 것
- 더 안전한 하네스를 설계하는 것
- 에이전트의 결과물을 더 정확하게 검토하는 것

Google Antigravity 2.0은 계속 진화한다. 하지만 이 시리즈에서 익힌 **에이전트 협업의 원칙**은 어떤 플랫폼에서도 적용된다.

이제 당신의 다음 프로젝트를 에이전트와 함께 시작하라.
