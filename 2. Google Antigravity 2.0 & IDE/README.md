## 1. 시리즈 소개

### 왜 이 교재 시리즈인가

Google Antigravity 2.0은 기존 CLI 기반 AI 코딩 도구와 근본적으로 다른 철학에서 출발한다. 터미널 창 하나에 의존하는 대신, 전용 Desktop App과 에이전트 협업 특화 IDE를 분리하여 제공한다. Desktop App은 에이전트의 두뇌 역할(Gemini 3.5 모델 연산, 샌드박스 관리)을 맡고, IDE는 개발자와 에이전트가 실시간으로 대화하며 코드를 검토·수락하는 협업 공간이 된다.

이 구조가 가져다 주는 가장 큰 변화는 **"에이전트가 만든 코드가 즉시 내 파일에 덮어씌워지는 불안"이 사라진다**는 점이다. 에이전트의 모든 작업은 격리된 샌드박스 안에서 이루어지고, 검토·수락 버튼을 누르기 전까지 실제 파일은 변경되지 않는다. 잘못됐다면 타임머신 롤백 하나로 전체 이력을 되돌린다.

이 시리즈는 그 구조를 처음부터 끝까지 직접 경험하도록 설계했다. 설치부터 시작하여, GEMINI.md 작성, MCP와 Skills 연결, 샌드박스 제어, 멀티에이전트 병렬 구현, 하네스 엔지니어링까지 16편에 걸쳐 완성형 풀스택 서비스를 만든다.

### 이 시리즈로 최종적으로 할 수 있는 것

- Antigravity 2.0 Desktop App과 IDE를 연동하여 에이전트 협업 환경을 완성할 수 있다.
- GEMINI.md에 @must·@avoid·@prefer 어노테이션을 활용하여 에이전트를 정밀하게 제어한다.
- MCP로 실제 PostgreSQL 스키마를 에이전트에 연결하고, Skills로 이미지 최적화·배포 자동화를 실행한다.
- Proposal 시스템으로 에이전트가 제안한 코드를 Diff View로 검토하고 선택적으로 수락한다.
- SvelteKit + NestJS + PostgreSQL 16 기반의 멀티 게시판 풀스택 서비스를 완성한다.
- 하네스 엔지니어링으로 에이전트가 절대 건드리면 안 되는 영역을 코드 레벨에서 강제한다.

## 2. Google Antigravity 2.0 에코시스템 개요

### 2.1 3-Tier 구조

```
┌─────────────────────────────────────────────────────────┐
│              Antigravity 2.0 Desktop App                │
│  로컬 에이전트 데몬 · 보안 샌드박스 · MCP·Skills 관리    │
└──────────────────────┬──────────────────────────────────┘
                       │  gRPC 양방향 스트리밍 (localhost)
┌──────────────────────▼──────────────────────────────────┐
│                  Antigravity IDE                        │
│  듀얼 엔진 뷰(에디터 + 에이전트 패널) · Proposal 시스템  │
│  타임머신 롤백 · 실시간 비용 게이지                      │
└─────────────────────────────────────────────────────────┘
                Antigravity CLI (ag 명령어)
```

### 2.2 핵심 개념 요약

| 개념 | 설명 |
|------|------|
| Secure Linux Sandbox | 에이전트 작업이 격리된 Alpine 컨테이너 안에서 실행됨 |
| Proposal System | 에이전트 코드를 제안(Proposal) 카드로 발행 → 인간이 검토 후 수락 |
| Timemachine | 원클릭으로 전체 파일 이력을 특정 시점으로 롤백 |
| GEMINI.md | 에이전트 규칙서. @must·@avoid·@prefer 어노테이션 지원 |
| Agent Skills | 이미지 처리·배포 등 특수 연산 전담 온디맨드 확장 패키지 |
| Artifacts | 에이전트 산출물(코드·스크린샷·테스트 결과)의 시각적 추적 단위 |
| multiAgentGate | 병렬 에이전트 간 파일 충돌 방지를 위한 Mutex 잠금 설정 |

#### 교재 07. 에이전트 스킬(Skills) 완벽 가이드

**한 줄 소개**: Skills는 MCP가 할 수 없는 물리 연산을 에이전트에게 부여하는 확장 패키지다.

**학습 목표**:
