## 3. 마일스톤 분할 전략

복잡한 프로젝트를 에이전트와 함께 구현할 때는 마일스톤으로 분할하는 것이 효과적이다. 각 마일스톤은 독립적으로 검증 가능해야 한다.

### 3.1 멀티 게시판 허브 마일스톤 계획

| 마일스톤 | 내용 | 검증 방법 | 예상 시간 |
|---------|------|----------|----------|
| M1: DB 스키마 | Prisma 스키마 + 마이그레이션 | Prisma Studio에서 확인 | 30분 |
| M2: 인증 모듈 | 회원가입, 로그인, JWT | curl로 API 테스트 | 45분 |
| M3: 게시판 CRUD | 게시판 목록, 게시글 CRUD | Postman/Thunder Client | 60분 |
| M4: 파일 업로드 | 이미지/동영상 업로드 | 파일 업로드 테스트 | 45분 |
| M5: 댓글 | 계층형 댓글, 좋아요 | API 통합 테스트 | 30분 |
| M6: 프론트엔드 기본 | 로그인, 게시판 목록/상세 | 브라우저 확인 | 90분 |
| M7: 프론트엔드 게시글 | 작성, 수정, 삭제, 파일 업로드 | 브라우저 확인 | 60분 |
| M8: 관리자 페이지 | 게시판 관리, 회원 관리 | 브라우저 확인 | 60분 |

### 3.2 마일스톤 간 의존성

```
M1 (DB 스키마)
  |
  +-- M2 (인증)
  |     |
  |     +-- M3 (게시판 CRUD)
  |           |
  |           +-- M4 (파일 업로드) --+
  |           |                      |
  |           +-- M5 (댓글)          |
  |                 |                |
  |                 +-- M6 (프론트 기본) <--+
  |                       |
  |                       +-- M7 (프론트 게시글)
  |                             |
  |                             +-- M8 (관리자)
```

## 4. 에이전트 지시문(Prompt) 작성 패턴

### 4.1 좋은 지시문의 구성 요소

```
[좋은 에이전트 지시문 템플릿]

목표: [한 문장으로 이번 마일스톤의 목표]

참고 문서:
- @docs/ERD.md (ERD 확인)
- @docs/API.md (API 명세 확인)
- @CLAUDE.md (프로젝트 규칙)

구현할 내용:
1. [구체적인 파일명과 내용]
2. [구체적인 파일명과 내용]

금지 사항:
- [이번 마일스톤에서 건드리지 않을 것]

완료 조건:
- [측정 가능한 완료 기준]
- [실행해야 할 검증 명령어]

완료 후:
- 생성한 파일 목록 보고
- 발생한 문제와 해결 방법 보고
```

### 4.2 나쁜 지시문 vs 좋은 지시문 비교

**나쁜 지시문**:
```
> 로그인 기능을 만들어줘
```

문제: 프레임워크 불명확, 어떤 파일에 만들지 불명확, JWT 설정 불명확

**좋은 지시문**:
```
> @docs/PRD.md (AUTH-001, AUTH-002, AUTH-003 섹션)과 
  @CLAUDE.md 를 읽고 다음을 구현해줘.
  
  목표: NestJS 인증 모듈 구현 (마일스톤 M2)
  
  구현할 파일:
  1. apps/backend/src/auth/auth.module.ts
  2. apps/backend/src/auth/auth.controller.ts
     - POST /auth/register
     - POST /auth/login
     - POST /auth/refresh
     - POST /auth/logout
  3. apps/backend/src/auth/auth.service.ts
     - register(dto): bcrypt 해시 후 DB 저장
     - login(dto): 자격증명 확인 후 JWT 발급
     - refreshToken(token): 리프레시 토큰 검증 후 새 accessToken
  4. apps/backend/src/auth/dto/register.dto.ts
  5. apps/backend/src/auth/dto/login.dto.ts
  6. apps/backend/src/auth/strategies/jwt.strategy.ts
  7. apps/backend/src/auth/guards/jwt-auth.guard.ts
  
  환경 변수 (.env에서 읽기):
  - JWT_SECRET
  - JWT_EXPIRES_IN=1h
  - JWT_REFRESH_SECRET
  - JWT_REFRESH_EXPIRES_IN=30d
  
  금지:
  - prisma/schema.prisma 수정 금지 (M1에서 완료)
  - app.module.ts 수정 금지 (별도로 처리)
  
  완료 조건:
  1. npx tsc --noEmit 에서 타입 오류 없음
  2. pnpm --filter backend test 에서 auth 테스트 통과
```

## 6. 마일스톤 1 실습: DB 스키마 생성

### 6.1 실습 프롬프트

```
> @docs/ERD.md 의 ERD를 읽고 prisma/schema.prisma를 작성해줘.
  
  요구사항:
  1. @docs/db.md 의 DB 규칙을 따른다
  2. 모든 모델에 UUID PK 사용 (gen_random_uuid())
  3. Soft delete 모델에 deletedAt DateTime? 추가:
     User, Post, Comment
  4. Board.boardType: enum BoardType {GENERAL GALLERY VIDEO QNA NOTICE FAQ INQUIRY FREE}
  5. Post.status: enum PostStatus {PUBLISHED DRAFT}
  6. User.role: enum Role {USER ADMIN}
  7. Post.metadata Json? 필드 추가 (게시판 유형별 데이터)
  
  스키마 완성 후:
  - npx prisma format 실행
  - npx prisma validate 실행
  - npx prisma migrate dev --name init 실행
  - 마이그레이션 성공 여부 보고
```

### 6.2 생성된 스키마 예시

```prisma
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

enum Role {
  USER
  ADMIN
}

enum BoardType {
  GENERAL
  GALLERY
  VIDEO
  QNA
  NOTICE
  FAQ
  INQUIRY
  FREE
}

enum PostStatus {
  PUBLISHED
  DRAFT
}

model User {
  id             String    @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  email          String    @unique @db.VarChar(255)
  hashedPassword String
  nickname       String    @unique @db.VarChar(50)
  role           Role      @default(USER)
  isActive       Boolean   @default(true)
  createdAt      DateTime  @default(now())
  updatedAt      DateTime  @updatedAt
  deletedAt      DateTime?

  posts        Post[]
  comments     Comment[]
  uploadedFiles File[]
  postLikes    PostLike[]

  @@map("users")
}

model Board {
  id          String    @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  name        String    @db.VarChar(100)
  slug        String    @unique @db.VarChar(100)
  boardType   BoardType
  description String?
  isActive    Boolean   @default(true)
  sortOrder   Int       @default(0)
  settings    Json?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt

  posts Post[]

  @@map("boards")
}

model Post {
  id          String     @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  title       String     @db.VarChar(200)
  content     String
  status      PostStatus @default(PUBLISHED)
  viewCount   Int        @default(0)
  isAnonymous Boolean    @default(false)
  isPinned    Boolean    @default(false)
  metadata    Json?
  boardId     String     @db.Uuid
  authorId    String     @db.Uuid
  createdAt   DateTime   @default(now())
  updatedAt   DateTime   @updatedAt
  deletedAt   DateTime?

  board    Board     @relation(fields: [boardId], references: [id])
  author   User      @relation(fields: [authorId], references: [id])
  comments Comment[]
  files    File[]
  tags     PostTag[]
  likes    PostLike[]

  @@index([boardId, createdAt(sort: Desc)])
  @@index([authorId])
  @@map("posts")
}

model Comment {
  id        String    @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  content   String
  depth     Int       @default(0)
  postId    String    @db.Uuid
  authorId  String    @db.Uuid
  parentId  String?   @db.Uuid
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
  deletedAt DateTime?

  post     Post      @relation(fields: [postId], references: [id])
  author   User      @relation(fields: [authorId], references: [id])
  parent   Comment?  @relation("CommentReplies", fields: [parentId], references: [id])
  replies  Comment[] @relation("CommentReplies")

  @@index([postId])
  @@map("comments")
}

model File {
  id            String   @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  originalName  String
  storedName    String
  filePath      String
  mimeType      String
  fileSize      BigInt
  thumbnailPath String?
  postId        String?  @db.Uuid
  uploaderId    String   @db.Uuid
  createdAt     DateTime @default(now())

  post     Post? @relation(fields: [postId], references: [id])
  uploader User  @relation(fields: [uploaderId], references: [id])

  @@map("files")
}

model Tag {
  id    String @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid
  name  String @unique @db.VarChar(50)
  color String @default("#6B7280")

  posts PostTag[]

  @@map("tags")
}

model PostTag {
  postId String @db.Uuid
  tagId  String @db.Uuid

  post Post @relation(fields: [postId], references: [id])
  tag  Tag  @relation(fields: [tagId], references: [id])

  @@id([postId, tagId])
  @@map("post_tags")
}

model PostLike {
  userId    String   @db.Uuid
  postId    String   @db.Uuid
  createdAt DateTime @default(now())

  user User @relation(fields: [userId], references: [id])
  post Post @relation(fields: [postId], references: [id])

  @@id([userId, postId])
  @@map("post_likes")
}
```

## 7. 마일스톤 2 실습: 인증 모듈

### 7.1 NestJS 백엔드 초기화

```bash
# NestJS 앱 생성
cd apps
npx @nestjs/cli new backend --package-manager pnpm<!-- R3 수정: --skip-git 옵션은 NestJS CLI 버전에 따라 지원 여부가 다름. 필요 시 --no-git 또는 생략 후 수동으로 .git 제거 -->
```

### 7.2 AuthService 핵심 코드

```typescript
// apps/backend/src/auth/auth.service.ts
import {
  Injectable,
  UnauthorizedException,
  ConflictException,
  ForbiddenException,
} from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';
import * as bcrypt from 'bcrypt';
import { PrismaService } from '../prisma/prisma.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';

@Injectable()
export class AuthService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly jwtService: JwtService,
    private readonly config: ConfigService,
  ) {}

  async register(dto: RegisterDto) {
    // 1. 이메일 중복 확인
    const existingEmail = await this.prisma.user.findUnique({
      where: { email: dto.email },
    });
    if (existingEmail) {
      throw new ConflictException('이미 사용 중인 이메일입니다');
    }

    // 2. 닉네임 중복 확인
    const existingNickname = await this.prisma.user.findUnique({
      where: { nickname: dto.nickname },
    });
    if (existingNickname) {
      throw new ConflictException('이미 사용 중인 닉네임입니다');
    }

    // 3. 비밀번호 해시
    const hashedPassword = await bcrypt.hash(dto.password, 12);

    // 4. 사용자 생성
    const user = await this.prisma.user.create({
      data: {
        email: dto.email,
        hashedPassword,
        nickname: dto.nickname,
      },
      select: {
        id: true,
        email: true,
        nickname: true,
        role: true,
        createdAt: true,
      },
    });

    return user;
  }

  async login(dto: LoginDto) {
    // 1. 사용자 조회
    const user = await this.prisma.user.findUnique({
      where: { email: dto.email, deletedAt: null },
    });

    if (!user) {
      throw new UnauthorizedException('이메일 또는 비밀번호가 올바르지 않습니다');
    }

    // 2. 계정 활성화 확인
    if (!user.isActive) {
      throw new ForbiddenException('비활성화된 계정입니다');
    }

    // 3. 비밀번호 검증
    const isPasswordValid = await bcrypt.compare(dto.password, user.hashedPassword);
    if (!isPasswordValid) {
      throw new UnauthorizedException('이메일 또는 비밀번호가 올바르지 않습니다');
    }

    // 4. JWT 발급
    const payload = { sub: user.id, role: user.role };

    const accessToken = this.jwtService.sign(payload, {
      secret: this.config.get('JWT_SECRET'),
      expiresIn: this.config.get('JWT_EXPIRES_IN', '1h'),
    });

    const refreshToken = this.jwtService.sign(payload, {
      secret: this.config.get('JWT_REFRESH_SECRET'),
      expiresIn: this.config.get('JWT_REFRESH_EXPIRES_IN', '30d'),
    });

    return {
      accessToken,
      refreshToken,
      user: {
        id: user.id,
        email: user.email,
        nickname: user.nickname,
        role: user.role,
      },
    };
  }
}
```
