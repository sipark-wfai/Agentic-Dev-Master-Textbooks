## 1. 사전 요구사항 확인

Claude Code를 설치하기 전에 개발 환경이 올바르게 준비됐는지 확인한다.

### 1.1 Node.js 확인

Claude Code는 Node.js 18 이상이 필요하다.

```bash
# Node.js 버전 확인
node --version
# 출력 예시: v20.11.0

# npm 버전 확인
npm --version
# 출력 예시: 10.2.4
```

Node.js가 설치되지 않았거나 18 미만인 경우, 다음 방법으로 설치한다.

**권장 방법: nvm (Node Version Manager) 사용**

```bash
# nvm 설치 (macOS/Linux)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 쉘 재시작 후 Node.js LTS 설치
nvm install --lts
nvm use --lts
nvm alias default node

# 설치 확인
node --version  # v20.x.x 이상
```

### 1.2 Git 확인

```bash
git --version
# 출력 예시: git version 2.43.0
```

Git이 없다면:
- macOS: `brew install git` 또는 Xcode Command Line Tools 설치
- Windows: https://git-scm.com 에서 다운로드

### 1.3 VS Code 확인

VS Code가 설치됐는지 확인하고, 없다면 https://code.visualstudio.com 에서 설치한다.

```bash
# VS Code 버전 확인
code --version
# 출력 예시: 1.87.0
```

## 2. macOS 설치 가이드

### 2.1 방법 1: npm 직접 설치 (권장)

```bash
# 전역 설치
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
# 출력 예시: 1.x.x
```

### 2.2 권한 오류 해결

macOS에서 npm 전역 설치 시 권한 오류가 발생하는 경우:

```bash
# 방법 1: sudo 사용 (권장하지 않음)
sudo npm install -g @anthropic-ai/claude-code

# 방법 2: npm 기본 디렉토리 변경 (권장)
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'

# ~/.zshrc 또는 ~/.bashrc에 추가
export PATH=~/.npm-global/bin:$PATH

# 쉘 재시작 후 재설치
npm install -g @anthropic-ai/claude-code
```

## 3. Windows 설치 가이드

Windows에서는 WSL2(Windows Subsystem for Linux 2)를 사용하는 것을 강력히 권장한다. Claude Code는 Unix 계열 환경에서 최적으로 동작한다.

### 3.1 WSL2 설치 절차

**Step 1: WSL2 활성화**

PowerShell을 관리자 권한으로 실행하고 다음 명령어를 실행한다.

```powershell
# WSL2 설치
wsl --install

# 설치 완료 후 재부팅
```

**Step 2: Ubuntu 설치**

```powershell
# Microsoft Store에서 Ubuntu 22.04 LTS 설치
wsl --install -d Ubuntu-22.04

# 또는 기존 WSL을 WSL2로 업그레이드
wsl --set-default-version 2
wsl --set-version Ubuntu 2
```

**Step 3: Ubuntu 초기 설정**

WSL2 Ubuntu 터미널을 열고 다음을 실행한다.

```bash
# 패키지 업데이트
sudo apt update && sudo apt upgrade -y

# 빌드 도구 설치
sudo apt install -y build-essential curl git

# nvm 설치
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

# Node.js 설치
nvm install --lts
nvm use --lts

# Claude Code 설치
npm install -g @anthropic-ai/claude-code

# 확인
claude --version
```

### 3.2 Windows PowerShell 환경 (대안)

WSL2 없이 PowerShell에서 직접 설치할 경우:

```powershell
# Node.js 설치 (winget 사용)
winget install OpenJS.NodeJS.LTS

# PowerShell 재시작 후
npm install -g @anthropic-ai/claude-code

# 경로 확인
where claude
```

### 3.3 Windows 경로 문제 해결

Windows에서 경로에 공백이나 한글이 포함된 경우 문제가 발생할 수 있다.

```powershell
# 사용자 홈 디렉토리 경로 확인
echo $env:USERPROFILE

# npm global 경로를 공백 없는 경로로 변경
npm config set prefix "C:\npm-global"

# 시스템 환경 변수에 C:\npm-global 추가
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\npm-global", "User")
```

## 4. Anthropic API 키 발급 절차

Claude Code를 사용하려면 Anthropic API 키가 필요하다.

### 4.1 계정 생성 및 API 키 발급

**Step 1**: 브라우저에서 https://console.anthropic.com 접속

**Step 2**: "Sign Up" 클릭 후 계정 생성
- 이메일 주소 입력
- 비밀번호 설정 (8자 이상, 특수문자 포함)
- 이메일 인증 완료

**Step 3**: 로그인 후 API Keys 페이지 이동
- 좌측 메뉴에서 "API Keys" 클릭
- 또는 직접 URL 접속: https://console.anthropic.com/settings/keys

**Step 4**: 새 API 키 생성
- "Create Key" 버튼 클릭
- 키 이름 입력 (예: "claude-code-dev")
- "Create Key" 확인

**Step 5**: API 키 복사 및 저장
- 생성된 키는 `sk-ant-api03-...` 형식이다
- 이 키는 한 번만 표시된다. 반드시 안전한 곳에 저장한다
- 다시 볼 수 없으므로 분실하면 새 키를 생성해야 한다

### 4.2 요금제 확인

| 요금제 | 월 무료 크레딧 | 적합한 용도 |
|--------|--------------|-------------|
| Free Tier | 없음 (유료만) | - |
| Pay as you go | 사용량 기반 | 개인 개발자 |
| Team | 고정 + 사용량 | 팀 단위 사용 |

Claude Code 사용 비용은 사용 패턴에 따라 크게 다르다. 처음에는 $5~10 크레딧을 충전하여 시작하는 것을 권장한다.

## 5. 환경 변수 설정

### 5.1 macOS/Linux 환경 변수 설정

```bash
# ~/.zshrc (zsh 사용자) 또는 ~/.bashrc (bash 사용자)에 추가
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-여기에-실제-키를-붙여넣는다"' >> ~/.zshrc

# 또는 nano로 직접 편집
nano ~/.zshrc

# 파일 맨 아래에 추가:
# export ANTHROPIC_API_KEY="sk-ant-api03-..."

# 변경사항 적용
source ~/.zshrc

# 설정 확인
echo $ANTHROPIC_API_KEY
```

### 5.2 Windows 환경 변수 설정

**PowerShell 방식:**

```powershell
# 현재 세션에만 적용
$env:ANTHROPIC_API_KEY = "sk-ant-api03-..."

# 영구 설정 (사용자 수준)
[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-api03-...", "User")

# 시스템 재시작 없이 적용 확인
$env:ANTHROPIC_API_KEY
```

**WSL2 방식 (권장):**

```bash
# ~/.bashrc에 추가
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-..."' >> ~/.bashrc
source ~/.bashrc
```

### 5.3 .env 파일 방식 (프로젝트별)

프로젝트마다 다른 API 키를 사용할 경우:

```bash
# 프로젝트 루트에 .env 파일 생성
cat > .env << EOF
ANTHROPIC_API_KEY=sk-ant-api03-...
EOF

# .gitignore에 .env 추가 (반드시!)
echo ".env" >> .gitignore
```

Claude Code는 프로젝트 루트의 `.env` 파일을 자동으로 읽는다.

## 6. 첫 번째 실행

### 6.1 Claude Code 시작

```bash
# 임시 테스트 폴더 생성
mkdir ~/hello-claude && cd ~/hello-claude

# Claude Code 실행

### 6.2 첫 실행 화면 설명

Claude Code를 처음 실행하면 다음과 같은 화면이 표시된다.

```
Claude Code v1.x.x

? Do you accept the terms of service? (Y/n)

Claude Code uses your Anthropic API key to make requests.
Usage will be billed to your Anthropic account.

> [여기에 입력]
```

- 이용약관에 동의(Y)한다.
- 프롬프트(>)에 자연어로 지시사항을 입력한다.

### 6.3 Hello World 실습

```

  console.log("Hello, World!");

Claude Code로 만든 첫 번째 파일입니다!

## 9. 자주 겪는 초기 오류 5가지와 해결법

### 오류 1: API 키 인증 실패

**증상**:
```
Error: Authentication failed. Check your ANTHROPIC_API_KEY.
```

**원인**: API 키가 환경 변수에 설정되지 않았거나 잘못된 값이다.

**해결**:
```bash
# 환경 변수 확인
echo $ANTHROPIC_API_KEY

# 비어 있다면 설정
export ANTHROPIC_API_KEY="sk-ant-api03-실제-키-값"

# 영구 설정
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-..."' >> ~/.zshrc
source ~/.zshrc
```

### 오류 2: `claude: command not found`

**증상**:
```
bash: claude: command not found
```

**원인**: npm 전역 설치 경로가 PATH에 포함되지 않았다.

**해결**:
```bash
# npm 전역 설치 경로 확인
npm root -g
# 출력 예시: /usr/local/lib/node_modules

# PATH에 추가
export PATH="$(npm bin -g):$PATH"
echo 'export PATH="$(npm bin -g):$PATH"' >> ~/.zshrc
source ~/.zshrc

# 재설치
npm install -g @anthropic-ai/claude-code
```

### 오류 3: Node.js 버전 충돌

**증상**:
```
Error: Claude Code requires Node.js 18 or higher. Current version: 16.x.x
```

**원인**: 오래된 Node.js 버전이 설치돼 있다.

**해결**:
```bash
# nvm으로 최신 LTS 설치
nvm install --lts
nvm use --lts
nvm alias default node

# 버전 확인
node --version

# Claude Code 재설치
npm install -g @anthropic-ai/claude-code
```

### 오류 4: Permission denied (macOS)

**증상**:
```
npm warn checkPermissions Missing write access to /usr/local/lib/node_modules
npm error code EACCES
```

**원인**: `/usr/local/lib/node_modules`에 쓰기 권한이 없다.

**해결**:
```bash
# npm 기본 디렉토리를 홈 폴더로 변경
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc

# 재설치
npm install -g @anthropic-ai/claude-code
```

### 오류 5: Windows WSL2에서 파일 경로 문제

**증상**:
```
Error: ENOENT: no such file or directory '/mnt/c/Users/...'
```

**원인**: Windows 경로와 WSL2 경로 혼용 문제다.

**해결**:
```bash
# WSL2에서는 항상 Linux 경로 사용
# 틀린 방법: cd /mnt/c/Users/username/project
# 올바른 방법: WSL2 홈 디렉토리에 프로젝트 생성

cd ~
mkdir projects
cd projects

# 또는 WSL2 경로를 올바르게 변환
wslpath -u "C:\Users\username\project"
```

## 10. 첫 번째 Claude Code 실습: 프로젝트 생성

설치가 완료됐다면 Claude Code를 활용하여 간단한 프로젝트를 만들어본다.

### 10.1 실습 목표

Node.js와 Express를 사용한 간단한 "Hello API" 서버를 Claude Code로 만든다.

### 10.2 실습 절차

**Step 1**: 프로젝트 폴더 생성 및 이동

```bash
mkdir hello-api && cd hello-api
claude
```

**Step 2**: Claude Code에 다음 지시사항 입력

```
Express.js로 간단한 API 서버를 만들어줘.
요구사항:
1. GET /hello 엔드포인트 - "Hello, World!" 반환
2. GET /time 엔드포인트 - 현재 시간 반환
3. package.json에 start 스크립트 추가
4. 포트 3000에서 실행
```

**Step 3**: Claude Code가 생성하는 파일 확인

Claude Code는 다음 파일을 생성한다:
- `package.json` — 프로젝트 설정 및 의존성
- `server.js` — Express 서버 코드
- `README.md` — 프로젝트 설명

**Step 4**: 서버 실행 확인

```bash
npm install
npm start
# 출력: Server running on port 3000
```

**Step 5**: API 테스트

```bash
curl http://localhost:3000/hello
# 출력: {"message":"Hello, World!"}

curl http://localhost:3000/time
# 출력: {"time":"2026-06-04T..."}
```

이 실습을 통해 Claude Code가 단순히 코드를 제안하는 것이 아니라, 완전히 동작하는 프로젝트를 처음부터 만들어낸다는 것을 직접 경험할 수 있다.
