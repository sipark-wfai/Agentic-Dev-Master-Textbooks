# 02. Cursor 설치 및 초기 설정

> **학습 목표**
> - macOS·Windows·Linux에서 Cursor를 설치하고 최초 실행한다
> - 계정을 생성하고 요금제를 선택한다
> - VS Code 설정과 확장을 마이그레이션한다
> - 모델을 초기 설정하고 BYO API Key를 연동한다
> - 설치 검증 체크리스트 20항목을 완료한다

---

## 1. 사전 요구사항

### 1.1 시스템 요구사항

| 항목 | 최소 사양 | 권장 사양 |
|------|-----------|-----------|
| OS | macOS 12+, Windows 10+, Ubuntu 20.04+ | 최신 버전 |
| CPU | 듀얼코어 2GHz | 쿼드코어 3GHz+ |
| RAM | 8GB | 16GB+ |
| 디스크 | 2GB 여유 공간 | SSD 10GB+ |
| 인터넷 | 필수 (AI 기능) | 100Mbps+ |

### 1.2 사전 설치 항목

Cursor 설치 전에 다음 도구가 있어야 한다.

```bash
# Node.js 18 이상 확인
node --version
# v20.11.0 (18 이상이면 OK)

# Git 확인
git --version
# git version 2.43.0

# pnpm 설치 (이 시리즈 프로젝트용)
npm install -g pnpm
pnpm --version
# 9.x.x
```

Node.js가 없다면 [https://nodejs.org](https://nodejs.org)에서 LTS 버전을 설치한다.

### 1.3 기존 VS Code 설정 백업

VS Code를 사용하던 경우, 설정을 마이그레이션하기 전에 백업한다.

```bash
# macOS VS Code 설정 위치
~/.config/Code/User/settings.json
~/.config/Code/User/keybindings.json
~/.vscode/extensions/

# macOS 백업 명령
cp ~/.config/Code/User/settings.json ~/Desktop/vscode-settings-backup.json
```

## 2. macOS 설치

### 2.1 다운로드

1. [https://cursor.sh](https://cursor.sh) 접속
2. **Download for Mac** 버튼 클릭
3. `Cursor-{버전}-darwin-{아키텍처}.dmg` 파일 다운로드
   - Apple Silicon(M1/M2/M3): `arm64` 버전
   - Intel Mac: `x64` 버전

### 2.2 설치

```
1. DMG 파일 더블클릭
2. Cursor 아이콘을 Applications 폴더로 드래그
3. Applications에서 Cursor 실행
4. "인터넷에서 다운로드된 앱입니다" 경고 → [열기] 클릭
5. 처음 실행 시 권한 요청 → 허용
```

### 2.3 CLI 도구 설치

터미널에서 `cursor` 명령어를 사용하려면 CLI를 설치한다.

```bash
# Cursor 앱 실행 후
# Cmd+Shift+P → "Install 'cursor' command in PATH" 실행

# 또는 수동으로 심볼릭 링크 생성
sudo ln -sf /Applications/Cursor.app/Contents/Resources/app/bin/cursor /usr/local/bin/cursor

# 확인
cursor --version
```

### 2.4 Homebrew로 설치 (선택)

```bash
brew install --cask cursor
```

## 3. Windows 설치

### 3.1 다운로드 및 설치

```
1. https://cursor.sh 접속
2. Download for Windows 클릭
3. CursorSetup-{버전}-win32-x64.exe 실행
4. 설치 마법사 진행
   - 설치 경로: C:\Users\{사용자}\AppData\Local\Programs\Cursor\
   - 바탕화면 바로가기 생성 체크
   - PATH 추가 체크 (권장)
5. 설치 완료 → Cursor 실행
```

### 3.2 Windows 환경 설정

```powershell
# PowerShell에서 확인
cursor --version

# Windows Terminal을 Cursor 내부 터미널로 설정
# Cursor Settings → Terminal → Default Profile → PowerShell 또는 Git Bash
```

### 3.3 WSL2와 함께 사용

Windows 개발 환경에서는 WSL2와 함께 사용하면 Linux 개발 환경을 그대로 활용할 수 있다.

```bash
# WSL2에서 Cursor 원격 연결
# Cursor → Remote Explorer → WSL Targets → 배포판 선택
```

## 4. Linux 설치

### 4.1 AppImage (모든 배포판)

```bash
# 다운로드
wget https://cursor.sh/download/linux -O cursor.AppImage

# 실행 권한 부여
chmod +x cursor.AppImage

# 실행
./cursor.AppImage

# 전역 사용을 위해 PATH에 추가
sudo mv cursor.AppImage /usr/local/bin/cursor
```

### 4.2 DEB 패키지 (Ubuntu/Debian)

```bash
# 다운로드 (버전은 최신으로 교체)
wget https://downloader.cursor.sh/linux/appImage/x64 -O cursor.deb

# 설치
sudo dpkg -i cursor.deb

# 의존성 오류 시
sudo apt-get install -f
```

### 4.3 의존성 설치 (Ubuntu)

```bash
sudo apt-get update
sudo apt-get install -y \
  libglib2.0-0 \
  libgtk-3-0 \
  libx11-xcb1 \
  libxcomposite1 \
  libxdamage1 \
  libasound2
```

## 5. 계정 생성 및 로그인

### 5.1 계정 생성

Cursor 첫 실행 시 로그인 화면이 나타난다.

```
1. [Sign Up] 클릭
2. 소셜 로그인 선택 (GitHub 권장)
3. GitHub → [Authorize Cursor] 클릭
4. 이메일 인증 완료
5. 이름 입력 → [Continue]
```

GitHub으로 로그인하면 나중에 프로젝트 연동이 편리하다.

### 5.2 요금제 선택 가이드

| 요금제 | 월 비용 | Fast Request | 대상 |
|--------|---------|--------------|------|
| Free | $0 | 50회/월 | 평가용, 가벼운 사용 |
| Pro | $20 | 500회/월 | 개인 개발자 (권장) |
| Business | $40/인 | 500회/월 | 팀 단위, Privacy Mode 팀 적용 |

**Fast Request**: GPT-4o, claude-sonnet-4-5, claude-opus-4-5 등 프리미엄 모델을 사용할 때 소비된다. Tab은 Fast Request를 소비하지 않는다.

```
# 요금제 선택 기준
혼자 개발, 하루 1~2시간 사용 → Free (체험), Pro (실무)
팀 개발, 코드 보안 중요 → Business
학생/오픈소스 → Free 또는 GitHub Student Pack 확인
```

## 6. VS Code 설정·확장·단축키 마이그레이션

### 6.1 자동 마이그레이션

Cursor 최초 실행 시 자동으로 VS Code 마이그레이션을 제안한다.

```
초기 설정 화면:
"Import settings from VS Code?" → [Import] 클릭

마이그레이션 항목:
✓ 설정 (settings.json)
✓ 키바인딩 (keybindings.json)
✓ 스니펫
✓ 설치된 확장 목록
```

### 6.2 수동 마이그레이션

자동 마이그레이션이 안 된 경우 수동으로 진행한다.

```bash
# macOS Cursor 설정 파일 위치
~/.cursor/User/settings.json
~/.cursor/User/keybindings.json

# VS Code 설정 복사
cp ~/.config/Code/User/settings.json ~/.cursor/User/settings.json
cp ~/.config/Code/User/keybindings.json ~/.cursor/User/keybindings.json
```

### 6.3 필수 확장 설치

```
Cursor에서 Extensions 패널 열기 (Cmd+Shift+X)

설치 필수:
- ESLint
- Prettier - Code formatter
- GitLens
- Error Lens
- Tailwind CSS IntelliSense (SvelteKit 프로젝트용)
- Svelte for VS Code
- Prisma

설치 권장:
- Auto Rename Tag
- Path Intellisense
- Import Cost
- Better Comments
```

### 6.4 VS Code와 Cursor 동시 사용

하나의 프로젝트를 VS Code와 Cursor에서 동시에 열지 않는 것이 좋다. 특히 파일 감시(watch) 프로세스가 충돌할 수 있다.

### 8.2 BYO (Bring Your Own) API Key 설정

자신의 API 키를 사용하면 Cursor Fast Request 한도와 별개로 모델을 사용할 수 있다.

**Anthropic API Key 연동:**

```
1. https://console.anthropic.com 접속
2. API Keys → Create Key
3. 키 복사

Cursor Settings → Models → OpenAI/Anthropic API Keys
→ Anthropic → [키 입력]
```

**OpenAI API Key 연동:**

```
1. https://platform.openai.com/api-keys 접속
2. Create new secret key
3. 키 복사

Cursor Settings → Models
→ OpenAI → [키 입력]
```

### 8.3 BYO Key 비용 모니터링

```
Anthropic 콘솔: https://console.anthropic.com/usage
OpenAI 콘솔: https://platform.openai.com/usage

월별 예산 설정 (OpenAI):
Platform → Billing → Usage limits
→ Hard limit: $50 (초과 시 차단)
→ Soft limit: $40 (초과 시 이메일 알림)
```

## 10. 자주 겪는 초기 오류 5가지

### 오류 1: "Failed to connect to AI"

```
원인: 인터넷 연결 문제 또는 방화벽
해결:
1. 인터넷 연결 확인
2. VPN 비활성화 후 재시도
3. 회사 방화벽의 경우 *.cursor.sh, *.anthropic.com 화이트리스트 등록
4. Cursor 재시작
```

### 오류 2: 확장이 Cursor에서 보이지 않는 경우

```
원인: VS Code Marketplace 접속 실패 또는 마이그레이션 누락
해결:
1. Extensions 패널 (Cmd+Shift+X) 열기
2. 확장 이름 검색 후 직접 설치
3. 또는: Cmd+Shift+P → "Extensions: Install Extensions"
```

### 오류 3: Tab 제안이 전혀 뜨지 않는 경우

```
원인: Tab 기능 비활성화 또는 모델 로딩 실패
해결:
1. Cursor Settings → Features → Tab → Enable Cursor Tab 켜기
2. 상태 바 하단에서 Tab 아이콘 클릭 → Enable 확인
3. Cursor 재시작
4. 파일 저장 후 다시 시도 (인덱싱 완료 후 작동)
```

### 오류 4: 코드베이스 인덱싱이 오래 걸리는 경우

```
원인: 대규모 프로젝트 또는 node_modules 포함
해결:
1. .cursorignore 파일 생성
   node_modules/
   .git/
   dist/
   build/
2. Cmd+Shift+P → "Cursor: Reindex Codebase"
```

### 오류 5: BYO API Key 인증 실패

```
원인: 키 형식 오류 또는 만료
해결:
1. 키 앞뒤 공백 없는지 확인
2. Anthropic: "sk-ant-"로 시작하는지 확인
3. OpenAI: "sk-"로 시작하는지 확인
4. 각 콘솔에서 키 활성 상태 확인
5. 키 삭제 후 재생성
```

## 11. 첫 번째 Hello World: Tab과 Chat으로 함수 생성

### 11.1 프로젝트 준비

```bash
# 터미널에서 실행 (Ctrl+` 로 Cursor 내장 터미널 열기)
mkdir hello-cursor
cd hello-cursor
npm init -y
npm install typescript @types/node -D
npx tsc --init
```

### 11.2 Tab으로 함수 생성

```typescript
// src/greeting.ts 생성 (Ctrl+N → 파일명 입력)

// 아래 주석을 타이핑하면 Tab이 나머지를 제안한다
// 사용자 이름과 언어를 받아서 적절한 인사말을 반환한다
// 지원 언어: 'ko', 'en', 'ja'

// "function greet" 까지 타이핑 후 Tab
```

예상 Tab 제안:
```typescript
function greet(name: string, language: 'ko' | 'en' | 'ja' = 'ko'): string {
  const greetings = {
    ko: `안녕하세요, ${name}님!`,
    en: `Hello, ${name}!`,
    ja: `こんにちは、${name}さん！`,
  };
  return greetings[language];
}

export { greet };
```

### 11.3 Chat으로 함수 개선

```
1. Cmd+L로 Chat 패널 열기
2. 입력:
   "@Files src/greeting.ts 이 함수에 다음을 추가해줘:
   1. 빈 이름 유효성 검사 (Error 발생)
   2. 이름 최대 길이 50자 제한
   3. JSDoc 주석"
3. Chat 응답 확인
4. [Apply] 버튼 클릭
5. 에디터에서 변경 내용 확인
```

### 11.4 결과 확인

```typescript
/**
 * 사용자 이름과 언어를 받아서 인사말을 반환한다
 * @param name - 사용자 이름 (1~50자)
 * @param language - 언어 코드 ('ko' | 'en' | 'ja'), 기본값 'ko'
 * @throws Error 이름이 비어있거나 50자를 초과하는 경우
 */
function greet(name: string, language: 'ko' | 'en' | 'ja' = 'ko'): string {
  if (!name || name.trim().length === 0) {
    throw new Error('이름을 입력해주세요');
  }
  if (name.trim().length > 50) {
    throw new Error('이름은 50자를 초과할 수 없습니다');
  }

  const greetings = {
    ko: `안녕하세요, ${name.trim()}님!`,
    en: `Hello, ${name.trim()}!`,
    ja: `こんにちは、${name.trim()}さん！`,
  };
  return greetings[language];
}

export { greet };
```
