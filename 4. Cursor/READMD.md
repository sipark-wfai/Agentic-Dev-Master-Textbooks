프로그래밍을 배우고 싶지만, 복잡한 개발 환경과 낯선 문법 앞에서 길을 잃으셨나요?

본 교재는 차세대 AI 코드 편집기인 **Cursor(커서)**를 활용하여, 코딩 입문자가 가장 빠르고 직관적으로 결과물을 만들어낼 수 있도록 안내합니다. 코드 작성부터 디버깅, 리팩토링까지 AI와 유기적으로 협업하는 방법을 배웁니다. 복잡한 문법 암기는 Cursor에게 맡기고, 여러분은 오직 **'아이디어와 논리'**에만 집중하세요.

## 1. 시리즈 소개

### 왜 이 교재 시리즈인가

Cursor는 설치 방법이 특별하지 않다. VS Code처럼 받아서 설치한다. 익숙한 에디터 화면, 익숙한 단축키, 익숙한 확장 플러그인이 그대로 있다. 그런데 Tab 키를 누르는 순간, 한 줄이 아니라 다음 함수 전체가 나타난다. Cmd+K를 누르고 "이 함수를 async로 바꿔줘"라고 타이핑하면 3초 뒤 변경이 완료된다. Cmd+Shift+I를 눌러 "게시글 CRUD API 전체를 만들어줘"라고 지시하면 에이전트가 10개 파일을 동시에 읽고 수정한다.

Cursor의 핵심 철학은 **"개발자가 평소 쓰던 환경을 바꾸지 않고 AI를 통합한다"** 는 것이다. CLI를 새로 배우거나, 별도 앱을 설치하거나, 새로운 인터페이스에 적응할 필요가 없다. 에디터 안에서 AI와 실시간으로 대화하며 코드를 만든다.

이 시리즈는 Cursor를 처음 접하는 모든 역할의 학습자를 위해 설계됐다. Tab 자동완성의 원리부터 시작해 Agent 모드, @멘션 컨텍스트 시스템, Cursor Rules, 멀티파일 자율 구현까지 15편을 통해 완성형 풀스택 서비스를 만든다.

### 이 시리즈로 최종적으로 할 수 있는 것

- Cursor Rules를 작성하여 에이전트가 프로젝트 규칙을 일관되게 따르도록 통제한다.
- Tab·Cmd+K·Chat·Agent 모드를 상황에 맞게 선택하여 개발 속도를 3배 이상 끌어올린다.
- @Codebase·@Docs·@Web·Notepads로 에이전트의 컨텍스트를 정밀하게 제어한다.
- Claude·GPT-4o·Gemini 모델을 상황별로 선택하여 품질과 비용을 최적화한다.
- SvelteKit + NestJS + PostgreSQL 16 기반의 멀티 게시판 풀스택 서비스를 완성한다.
- Privacy Mode와 BYO Key로 팀의 보안 정책에 맞게 Cursor를 배포한다.

## 2. Cursor 에코시스템 개요

### 2.1 Cursor의 4대 핵심 기능

```
┌─────────────────────────────────────────────────────────┐
│                    Cursor 에디터                         │
│  (VS Code 포크 — 모든 VS Code 확장·단축키 호환)          │
├──────────┬────────────┬──────────────┬──────────────────┤
│   Tab    │  Cmd+K     │  Chat        │  Agent           │
│ 예측 편집 │ 인라인 편집 │ (Cmd+L)     │ (Cmd+Shift+I)    │
│ 자동완성  │ 즉각 수정  │ 대화형 질의  │ 멀티파일 자율 구현│
│ 무제한   │ 빠른 수정  │ Apply 적용   │ Background 실행  │
└──────────┴────────────┴──────────────┴──────────────────┘
                         │
              ┌──────────┴──────────┐
              │  @멘션 컨텍스트 시스템 │
              │ @Codebase @Files    │
              │ @Docs @Web @Git     │
              │ @Notepads           │
              └──────────────────────┘
```

### 2.2 핵심 개념 요약

| 개념 | 설명 |
|------|------|
| Tab (예측 편집) | 코드 흐름을 학습하여 다음에 올 코드를 멀티라인으로 예측·제안 |
| Cmd+K (인라인 편집) | 선택 영역을 자연어로 즉각 수정. Accept/Reject로 검토 |
| Chat (Cmd+L) | 우측 패널 AI 채팅. Apply 버튼으로 에디터에 직접 적용 |
| Agent/Composer | 여러 파일을 동시에 읽고 수정하는 자율 에이전트 모드 |
| Cursor Rules | .cursor/rules 에 저장하는 프로젝트별 AI 규칙서 |
| @멘션 | Chat·Agent에서 파일·문서·웹·코드베이스를 컨텍스트로 주입 |
| Notepads | 반복 사용하는 컨텍스트를 저장하는 영구 메모장 |
| Privacy Mode | 코드가 Anthropic/OpenAI 서버로 전송되지 않는 격리 모드 |
| BYO Key | 자신의 API 키를 Cursor에 연결하는 방식 |
| Codebase Index | Cursor가 프로젝트 전체를 임베딩하여 시맨틱 검색 가능하게 만드는 과정 |

### 2.3 타 에이전틱 도구와 비교

| 항목 | Claude Code | Antigravity 2.0 | ChatGPT Codex | **Cursor** |
|------|------------|----------------|--------------|-----------|
| 인터페이스 | 터미널 CLI | Desktop App + IDE | ChatGPT 웹 | **VS Code 기반 에디터** |
| 설치 | npm 전역 설치 | 앱 2개 설치 | 설치 불필요 | **앱 단독 설치** |
| 기존 VS Code 호환 | ✗ | 별도 IDE | ✗ | **✅ 완전 호환** |
| 실시간 코드 편집 | 파일 직접 수정 | Proposal 카드 수락 | PR 리뷰 | **인라인·실시간 하이라이트** |
| 자동완성(Tab) | ✗ | ✗ | ✗ | **✅ 예측 편집** |
| 인라인 편집 | ✗ | ✗ | ✗ | **✅ Cmd+K** |
| 에이전트 규칙서 | CLAUDE.md | GEMINI.md | AGENTS.md | **Cursor Rules (.cursor/rules)** |
| 모델 선택 | Claude만 | Gemini만 | OpenAI만 | **Claude·GPT·Gemini 모두** |
| 오프라인·프라이버시 | 제한적 | 제한적 | ✗ | **✅ Privacy Mode** |

### STAGE 2 — 핵심 설정·기능 (교재 03~08)

#### 교재 03. Cursor Rules 작성 완벽 가이드

**한 줄 소개**: Cursor Rules는 CLAUDE.md·GEMINI.md·AGENTS.md와 동등한 Cursor의 에이전트 규칙서다. 잘 쓴 Rules 하나가 수백 번의 교정 지시를 대신한다.

**학습 목표**:
- .cursor/rules의 적용 범위(Always On·Auto Attached·Manual)를 이해하고 선택한다.
- 프로젝트 전체·특정 폴더·글로벌 세 가지 레벨의 Rules를 설계한다.
- 멀티 게시판 프로젝트용 Rules를 직접 완성한다.

**주요 내용**: Cursor Rules란, 파일 위치·적용 방식 3가지, Rules 작성 원칙, 필수 섹션 구성, 멀티 게시판 Rules 전체 예시(80줄+), frontend.md·backend.md·style.md 분리 전략, 비교 사례 5가지, Notepads 연계, 품질 체크리스트

**대상 독자**: 전체 | **선수 교재**: 01·02 | **예상 학습 시간**: 90~120분

---

#### 교재 04. Tab 자동완성 마스터

**한 줄 소개**: Tab은 단순 자동완성이 아니다. 코드베이스 전체를 이해한 AI가 다음에 올 코드를 블록 단위로 예측한다.

**학습 목표**:
- Tab 예측 편집의 작동 원리(코드베이스 인덱싱 기반)를 이해한다.
- Tab·Ctrl+→·Esc를 상황에 맞게 사용하여 타이핑 효율을 높인다.
- Tab이 잘 작동하는 패턴과 거절이 필요한 상황을 판단한다.

**주요 내용**: Tab vs GitHub Copilot Tab 차이, 작동 원리, 수락 방법(Tab·Ctrl+→·Esc), 잘 작동하는 패턴(반복 DTO·테스트·임포트), 실전 예시 10가지(NestJS·SvelteKit·Prisma), Tab을 더 잘 작동시키는 방법(Rules 활용), Fast Request 비소비 특성

**대상 독자**: 개발자 | **선수 교재**: 02 | **예상 학습 시간**: 60~90분

---

#### 교재 05. Chat & Inline Edit 마스터

**한 줄 소개**: Chat은 대화하며 코드를 만드는 공간이고, Cmd+K는 선택한 코드를 즉각 바꾸는 마법 키다.

**학습 목표**:
- Chat 패널(Cmd+L)과 Inline Edit(Cmd+K)의 차이와 선택 기준을 이해한다.
- Apply·Accept·Reject로 AI 제안을 검토하고 적용하는 흐름을 익힌다.
- 실전 시나리오 10가지에서 Chat vs Cmd+K 중 올바른 것을 선택한다.

**주요 내용**: Chat 패널 구조, Apply 흐름, New Chat vs Continue 선택, Cmd+K 동작 방식(선택·무선택·터미널), Accept/Reject, Chat vs Cmd+K 비교표, @멘션 기초(Files·Codebase), 실전 시나리오 10가지

**대상 독자**: 전체 | **선수 교재**: 02·03 | **예상 학습 시간**: 90~120분

#### 교재 06. Agent 모드 완벽 가이드

**한 줄 소개**: Agent는 여러 파일을 동시에 읽고 수정하는 Cursor의 자율 구현 엔진이다. 큰 태스크는 Agent에게 맡긴다.

**학습 목표**:
- Agent(Composer) 모드와 Chat의 차이를 명확히 구분한다.
- Agent 지시문을 작성하여 멀티파일 구현을 자율로 실행시킨다.
- Background Agent를 설정하고 완료 알림을 수신한다.

**주요 내용**: Agent vs Chat 차이, 실행 방법(Cmd+Shift+I), 동작 원리(읽기→계획→수정→검토), 변경 파일 목록 확인, 개별 Accept/Reject, Background Agent 설정, 지시문 패턴 10가지, Agent 멈춤·오류 대처, 마일스톤 1 실습(DB 스키마 자율 구현)

**대상 독자**: 개발자 | **선수 교재**: 04·05 | **예상 학습 시간**: 90~120분

#### 교재 07. @멘션 컨텍스트 시스템

**학습 목표**:

- Notepads를 생성하고 반복 사용 컨텍스트로 활용한다.

**주요 내용**: @멘션 시스템 개요, @Codebase(임베딩 기반 검색), @Files(파일·폴더 참조), @Docs(공식 문서 URL 인덱싱·커스텀 추가), @Web(실시간 검색), @Git(커밋·diff), @Notepads(생성·참조·관리), @멘션 조합 전략, 실전 시나리오 10가지

**대상 독자**: 개발자 | **선수 교재**: 05·06 | **예상 학습 시간**: 90~120분
