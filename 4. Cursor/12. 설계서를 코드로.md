## 1. ERD → Prisma 스키마 변환

### 1.1 변환 지시문

```
"@Docs docs/erd.md ERD를 참조해서
apps/backend/prisma/schema.prisma를 작성해줘.

변환 규칙:
1. ERD의 각 엔티티 → Prisma model
2. ERD의 FK 관계 → @relation
3. 모든 모델에 추가:
   - id: String @id @default(cuid())
   - createdAt: DateTime @default(now())
   - updatedAt: DateTime @updatedAt
   - deletedAt: DateTime?
4. 자주 조회되는 FK 필드에 @index 추가"
```

### 1.2 생성된 스키마 예시

```prisma
model Post {
  id        String    @id @default(cuid())
  title     String
  content   String    @db.Text
  boardId   String
  authorId  String
  board     Board     @relation(fields: [boardId], references: [id])
  author    User      @relation(fields: [authorId], references: [id])
  comments  Comment[]
  files     File[]
  viewCount Int       @default(0)
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
  deletedAt DateTime?

  @@index([boardId])
  @@index([authorId])
  @@index([deletedAt])
  @@index([createdAt])
}
```

## 2. API 명세 → NestJS 컨트롤러 변환

### 2.1 변환 지시문

```
"@Docs docs/api.md 게시글 CRUD API 명세를 참조해서
NestJS PostController를 구현해줘.

구현 요구사항:
- Swagger @ApiOperation, @ApiResponse 데코레이터 포함
- JwtAuthGuard로 인증 보호 (GET 제외)
- 응답은 항상 { data: T, meta?: PaginationMeta } 구조
- DTO 유효성 검사 (class-validator)"
```

### 2.2 생성된 컨트롤러 예시

```typescript
@Controller('posts')
@ApiTags('게시글')
export class PostController {
  constructor(private readonly postService: PostService) {}

  @Get()
  @ApiOperation({ summary: '게시글 목록 조회' })
  findAll(@Query() query: FindPostsDto) {
    return this.postService.findAll(query);
  }

  @Post()
  @UseGuards(JwtAuthGuard)
  @ApiBearerAuth()
  @ApiOperation({ summary: '게시글 작성' })
  create(@Body() dto: CreatePostDto, @Request() req: RequestWithUser) {
    return this.postService.create(dto, req.user.id);
  }

  @Patch(':id')
  @UseGuards(JwtAuthGuard)
  @ApiBearerAuth()
  @ApiOperation({ summary: '게시글 수정 (작성자 또는 BOARD_ADMIN)' })
  update(@Param('id') id: string, @Body() dto: UpdatePostDto, @Request() req: RequestWithUser) {
    return this.postService.update(id, dto, req.user);
  }

  @Delete(':id')
  @UseGuards(JwtAuthGuard)
  @ApiBearerAuth()
  @ApiOperation({ summary: '게시글 삭제 (소프트 삭제)' })
  remove(@Param('id') id: string, @Request() req: RequestWithUser) {
    return this.postService.remove(id, req.user);
  }
}
```
