## 주요 발견사항 (R5 신규)

1. **Opus 버전 업**: claude-opus-4-8이 2026년 5월 출시되어 교재의 opus-4-6은 구버전. 교재 내 용례는 기능 설명 목적으로 허용 가능하나 주석 권장.
2. **Haiku 버전**: haiku-4-6 명칭 미확인; 공식은 haiku-4-5-20251001. 수정 권장.
3. **/stats vs /cost**: Pro/Max 구독자는 /stats, API 사용자는 /cost. 교재는 구분 없이 /cost만 언급.
4. **Agent Teams**: 2026년 2월 출시된 Agent Teams 기능이 있으나 교재 범위(15편) 내에서는 언급 불필요.
5. **Claude Agent SDK 과금 변경**: 2026년 6월 15일부로 Agent SDK는 별도 크레딧 풀로 분리. 교재 영향 없음(15편 범위 외).
