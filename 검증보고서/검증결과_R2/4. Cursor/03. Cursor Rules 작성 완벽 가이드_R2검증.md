## 잔존/신규 발견 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| Rules 파일 경로 및 형식 | `.cursor/rules` (확장자 없는 파일) 또는 `.cursor/rules/*.md` | 현행 Cursor 공식: `.cursor/rules/` 폴더 안의 `.mdc` 파일 사용. `alwaysApply`, `globs` 등 frontmatter를 `.mdc` 파일에 정의. 교재가 `.md` 및 확장자 없는 파일을 정식으로 안내하는 것은 구버전 방식 | 2절 전체, 3절 |
| `.cursorrules` 파일 언급 없음 | 교재가 `.cursor/rules` (구버전식 단일 파일) 방식만 설명 | 현재 Cursor는 `.cursorrules`(구버전 레거시)와 `.cursor/rules/*.mdc`(신버전 권장) 두 방식 모두 지원. 신버전 `.mdc` 형식이 권장됨 | 전체 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| Auto Attached frontmatter 형식 | `--- globs: [...] ---` | 실제 `.mdc` 파일의 frontmatter에서 `globs`와 `alwaysApply` 필드를 사용. 교재의 YAML frontmatter 표기 방식은 대체로 맞지만 `.mdc` 확장자 명시 필요 | 3.2절 |
| Notepads 위치 | `.cursor/notepads/` 폴더 언급 없음, UI 통해 생성만 안내 | Cursor Notepads는 `.cursor/notepads/` 폴더에 `.md` 파일로도 생성 가능 | 7.2절 |
| 글로벌 Rules 경로 | `~/.cursor/rules` | 글로벌 Rules의 정확한 경로는 공식 문서 확인 필요. 기능 자체는 존재 | 2.3절 |

### 🟢 확인됨
- Rules의 역할과 목적 설명 정확 (CLAUDE.md, GEMINI.md와 동일 역할)
- Always On, Auto Attached, Manual 세 가지 적용 방식 구분 정확
- 좋은 Rules 작성 원칙(구체적·측정 가능·AI 실행 가능) 정확
- 금지 사항 명확히 기재하는 방식 정확
- NestJS, SvelteKit, Prisma 코드 패턴 정확
