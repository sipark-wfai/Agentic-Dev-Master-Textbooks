### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| Prisma $extends 내 `this` 참조 | `(this as any).update(...)`, `(this as any).updateMany(...)` | `$extends` Query Extension 내에서 `this`로 같은 모델을 참조하는 방식은 Prisma 공식 권장 패턴이 아님. 순환 참조 위험. 실제 소프트 삭제 구현에는 `query` 파라미터 대신 직접 Prisma client를 사용해야 함 | 8.4절 |
| Background Agent 설정 경로 | `Cursor Settings → Features → Background Agent → Enable` | Background Agent는 버전에 따라 위치가 다를 수 있음. 확인 권고 | 4.1절 |
| Agent의 파일 삭제 | "파일 삭제 (승인 후)" | Agent가 파일을 삭제할 때 항상 명시적 승인이 필요한지 여부는 버전별로 다를 수 있음 | 1.2절 |
