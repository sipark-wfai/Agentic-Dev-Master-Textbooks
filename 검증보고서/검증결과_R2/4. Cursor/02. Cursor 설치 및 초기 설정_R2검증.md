### 🟢 확인됨
- macOS 설정 경로 `~/Library/Application Support/Code/User/` 정확
- Cursor 설정 위치 `~/.cursor/User/settings.json` 정확
- Agent 단축키 Cmd+I 정확
- Chat 단축키 Cmd+L 정확
- Inline Edit 단축키 Cmd+K 정확
- Homebrew 설치 명령 `brew install --cask cursor` 정확
- CLI 심볼릭 링크 경로 정확
- Tab 기능 활성화 위치 설명 정확
- API Key 모니터링 URL 정확 (console.anthropic.com/usage)
