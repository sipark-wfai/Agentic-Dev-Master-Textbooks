## 잔존/신규 발견 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| require('fs') ESM 혼용 | `require('fs').mkdirSync(dir, { recursive: true })` | NestJS TypeScript/ESM 환경에서 CommonJS `require()` 혼용은 설정에 따라 런타임 오류 유발. `import { mkdirSync } from 'fs'` 사용 필요 | 섹션 3.3 FilesModule |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| SvelteKit 설치 명령어 | `npm create svelte@latest frontend` | Svelte 5 기준 현재 권장 방식은 `npx sv create frontend`. 구버전 방식이나 기능상 동작할 수 있음 | 섹션 2.1 |
| `post.thumbnail` 미정의 | `{#if post.thumbnail}` | 공유 타입 `Post` 인터페이스에 `thumbnail` 필드 정의 없음. 런타임에는 동작하나 TypeScript 타입 오류 발생 | 섹션 2.6 PostCard |
| `{@html post.content}` XSS 위험 | FAQ 아코디언에서 `{@html post.content}` | XSS 취약점. sanitize 라이브러리 없이 사용하면 악성 스크립트 실행 가능. DOMPurify 적용 필요 | 섹션 2.6 PostCard |
| pnpm add tailwindcss | `pnpm add tailwindcss @tailwindcss/typography` | TailwindCSS v4에서는 설치 방법이 변경됨(`@tailwindcss/vite` 등). 버전 미명시로 혼동 가능 | 섹션 2.1 |
