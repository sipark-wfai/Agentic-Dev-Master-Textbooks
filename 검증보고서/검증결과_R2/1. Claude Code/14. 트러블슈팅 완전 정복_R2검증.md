### 🟡 주의

|------|----------|------------------|------|
| docker-compose 구버전 명령어 | `docker-compose down && docker-compose up -d postgres` | Docker Compose v2에서 `docker compose`(하이픈 없음)가 표준. 구버전 CLI에서는 동작하나 최신 환경에서 deprecated 경고 또는 명령어 없음 오류 발생 가능 | 시나리오 4 |

| 모델명 불확실성 | `--model claude-haiku-4-5` | `claude-haiku-4-5` 모델명의 실제 배포 여부 불확실. Anthropic 공식 API 모델 목록에서 `claude-haiku-3-5`가 확인되며, `4-5` 버전명은 미래형 가능성 있음 | 시나리오 1 |
| `settings.json permissions.deny` | `"permissions": {"deny": [".env", ...]}` | 13편과 동일하게 Claude Code 공식 스펙에서 이 구조의 지원 여부 불확실 | 시나리오 8 |
