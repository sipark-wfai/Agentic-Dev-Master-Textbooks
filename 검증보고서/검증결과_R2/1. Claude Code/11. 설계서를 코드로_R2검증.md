### 🟡 주의

|------|----------|------------------|------|
| `where` 타입 불안전성 | `const where: Record<string, unknown> = {...}` | Prisma에서 `where` 절에는 모델별 생성 타입(예: `Prisma.PostWhereInput`)을 사용하는 것이 권장됨. 현재 코드는 TypeScript strict 모드에서 타입 안전성 저하 | 섹션 3.2 |
| OptionalJwtAuthGuard 미구현 | `@UseGuards(OptionalJwtAuthGuard)` 사용 | NestJS 내장이 아닌 커스텀 Guard이나 구현 예시 없음. 독자가 직접 구현해야 하는 부분임을 안내 필요 | 섹션 3.1 |
