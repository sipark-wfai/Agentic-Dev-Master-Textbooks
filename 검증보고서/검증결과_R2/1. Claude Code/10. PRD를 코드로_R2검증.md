### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| Prisma UUID 기본값 | `@default(dbgenerated("gen_random_uuid()")) @db.Uuid` | Prisma v5에서 UUID를 `@default(uuid())`로도 생성 가능. `dbgenerated("gen_random_uuid()")`는 PostgreSQL 함수를 직접 사용하는 방식으로 정확하나, Prisma v5의 `@default(uuid())` 방식도 함께 소개하면 좋음 | 6.2절 스키마 |
| `@nestjs/cli` 생성 시 `--skip-git` 옵션 | `npx @nestjs/cli new backend --package-manager pnpm --skip-git` | `--skip-git` 옵션이 현재 NestJS CLI에서 지원되는지 확인 필요. 옵션명이 `--no-git`일 수 있음 | 7.1절 |
| pnpm 스크립트 `--parallel` | `pnpm --parallel --filter './apps/*' dev` | `pnpm --parallel`과 `pnpm -r` 차이. `--parallel` 대신 `-r` 또는 `-w` 사용이 더 일반적 | 2.1절 루트 package.json |
| RefreshToken 만료 | `JWT_REFRESH_EXPIRES_IN=30d` | 08편에서 "30일"과 "7일" 불일치 언급. 10편에서는 30d로 표기 — 08편과 불일치 | 7.2절 환경변수 |
