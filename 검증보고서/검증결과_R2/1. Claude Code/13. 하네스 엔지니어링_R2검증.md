## 잔존/신규 발견 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| settings.json `permissions` 섹션 | `"permissions": {"allow": [...], "deny": [...]}` | Claude Code `.claude/settings.json`의 공식 권한 설정 스펙은 `bash`, `read`, `write` 등 도구별 허용/차단 방식임. `allow/deny` 경로 배열 구조는 공식 문서에서 확인되지 않음 | 섹션 2.2, 섹션 3 |
| settings.json `limits` 섹션 | `"limits": {"maxFilesPerSession": 100, "maxTokensPerRequest": 50000, ...}` | Claude Code 공식 스펙에 존재하지 않는 `limits` 섹션. 실제 적용되지 않으며 교재를 따라 설정해도 효과 없음 | 섹션 3 |
| Hook 변수 치환 방식 | `"command": ".claude/hooks/human-approval.sh \"${command}\" PreToolUse"` | Claude Code Hooks는 `${command}`, `${file}` 직접 인자 치환을 지원하지 않음. 실제로는 stdin으로 JSON을 전달하므로 스크립트 내에서 `jq` 등으로 파싱해야 함 | 섹션 3 hooks 설정 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| `CLAUDE_CONTEXT_TOKENS` 환경변수 | `CURRENT_TOKENS="${CLAUDE_CONTEXT_TOKENS:-0}"` | Claude Code가 이 환경변수를 Hook에 실제로 제공하는지 공식 문서에서 확인 불가. 제공되지 않으면 항상 0으로 인식됨 | 섹션 2.4 |
| `CLAUDE_MAX_TOKENS` 환경변수 | `MAX_TOKENS="${CLAUDE_MAX_TOKENS:-200000}"` | 동일하게 실제 제공 여부 불확실. 기본값 200000 고정 사용 시 실제 모델 한계와 다를 수 있음 | 섹션 2.4 |

### 🟢 확인됨 (정확)
- 협업 크레딧 "Claude Sonnet 4.6" 정상 기재
- 하네스 엔지니어링 개념(비결정론적 에이전트를 결정론적으로 제어) 정확
- 프롬프트 엔지니어링 vs 하네스 엔지니어링 비교표 개념 정확
- PreToolUse exit 2로 차단하는 패턴 정확
- Hooks 이벤트 유형(PreToolUse, PostToolUse, Stop) 정확
- `any` 타입 감지 패턴(`grep -c ": any"`) 정확
- 보안 키워드 감지 패턴 정확
- 하네스 성숙도 모델 Level 0~5 개념 정확
- 역할별 하네스 설계 전략 개념 정확
- `chmod +x` 권한 설정 정확
- production-deployment-guard.sh 내 패턴 매칭 로직 정확
- Hooks 이벤트 설정 구조(`matcher`, `hooks`, `type`, `command`) 정확
