### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| Mermaid erDiagram 문법 | `datetime deletedAt` 등 Mermaid 타입 표기 | Mermaid erDiagram에서 `datetime` 타입은 표준이 아님. 실제로는 `DateTime`이나 문자열로 표현해야 함. 단, Mermaid가 타입을 유효성 검증하지 않아 렌더링 자체는 됨 | 2.2절 ERD |
| API 명세서 JSON 코드블록 | 마크다운 내에서 JSON을 인라인으로 표현 | 코드블록 없이 JSON을 표현하는 구간이 있어 마크다운 렌더링에서 혼란 가능 | 3.1절 API 명세 예시 |
| 로그인 시퀀스 다이어그램 | "사용자 -> 프론트엔드: POST /auth/login" | Mermaid sequenceDiagram 형식이 아닌 텍스트로만 표현. 실제로는 sequenceDiagram 블록 안에 작성해야 함. 교재 목적상 텍스트 표현은 이해 가능하나, 실습하려면 형식 변환 필요 | 4.2절 |
| `gen_random_uuid()` | Prisma에서 `@default(dbgenerated("gen_random_uuid()"))` | PostgreSQL 13+에서 지원. PostgreSQL 16을 사용하므로 정확. 단, PostgreSQL 12 이하에서는 `uuid-ossp` 확장 필요. 교재에서 PG16을 사용하므로 문제없음 | 2.1절 |
