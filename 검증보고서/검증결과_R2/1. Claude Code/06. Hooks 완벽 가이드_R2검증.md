## 잔존/신규 발견 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| Hook 명령어에서 `"${command}"` 사용 | settings.json의 "command" 필드 인라인에서 여전히 `${command}` 변수 치환 방식 사용 | 3.3절 주의에서는 stdin 파싱을 명시했으나, Hook 2(DROP 차단), Hook 9(API 로깅) 등의 인라인 command 문자열에서 여전히 `$CMD` 쉘 변수를 직접 사용. 이는 일관성이 없고 독자 혼란 유발 | Hook 2, Hook 9 JSON 예제 |
| settings.json의 Hooks에서 `"${file}"` | 전체 설정 파일(섹션 6)과 13편의 settings.json에 `"${file}"`, `"${command}"` 변수 치환 방식 존재 | 이미 수정됐다고 했으나, 섹션 3.3 주의사항과 실제 JSON 예시 사이에 불일치가 남아 있음 | 6절 전체 설정 파일 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| `Notification` 이벤트 | 이벤트 유형으로 설명 | 실제 Claude Code Hooks에서 `Notification` 이벤트가 지원되는지 공식 문서 확인 필요 | 2.3절 |
| `SubagentStop` 이벤트 | 검증 중점 항목에 언급됐으나 본문에 없음 | 교재에서 다루지 않은 것은 정확. 하지만 공식 이벤트명이 `SubagentStop`인지 확인 필요 | - |
| Hook에서 exit code 2 동작 | "도구 실행을 취소하고 에이전트에게 차단 사유 전달" | 실제로 exit code 2가 PreToolUse에서 차단을 의미하는지 공식 문서 확인 필요 | 3.4절 |
