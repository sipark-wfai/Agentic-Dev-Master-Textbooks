## 4. 핵심 발견사항

### 4-1. R1 수정 반영 패턴

**잘 반영된 유형**: 오타·표기 수정, docker-compose version 필드 제거, pnpm 문법 수정, 가격 면책 문구 추가

**반영이 저조한 유형**: 코드 레벨 API 변경 (Prisma `$use()` → `$extends()`), CLI 미존재 옵션 수정, 구현 코드 예시 추가, 경로·설정 명세 업데이트

### 4-2. 도구 성숙도와 할루시네이션의 상관관계

Antigravity(WHI 0.286) vs ChatGPT Codex(WHI 0.075)의 대비는 **공개 문서의 성숙도가 AI 생성 교재의 사실 정확성을 결정하는 핵심 변수**임을 실증한다. 동일 집필 방법론 하에서도 참조 가능한 공식 문서의 양·질이 오류율을 결정한다.

## 5. 연구 시사점

**WHI 지표의 유효성**: 심각도별 가중치(심각 1.0, 주의 0.3)를 적용한 WHI는 단순 오류 개수 대비 교재 품질을 정밀하게 표현한다. R1→R2 평균 개선율 25%는 1회 검증-수정 사이클의 실질적 효과를 정량화한다.

**수정 반영의 비대칭성**: 문구·표기 수정은 즉각 반영되는 반면 코드 레벨 변경은 저조하다. 교재 수정 워크플로우에서 **코드 검증 단계의 별도 분리**가 필요하다.

**집필 시점의 한계**: Antigravity 교재 초반부의 높은 WHI는 공식 문서 성숙 전 집필에 따른 구조적 문제로, 이는 신규 도구 교재 집필 시 공식 문서 안정화 시점까지 대기하거나 잦은 개정 주기를 계획할 필요가 있음을 시사한다.
