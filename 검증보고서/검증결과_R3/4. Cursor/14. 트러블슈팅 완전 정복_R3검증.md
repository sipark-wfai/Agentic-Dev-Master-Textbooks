### 🟢 확인됨 (정확)
- macOS 캐시 경로 `~/Library/Caches/Cursor/` 정확 (R1 수정 완료)
- Windows 캐시 경로 `%LOCALAPPDATA%\Cursor\Cache` 정확 (R1 수정 완료)
- 오류 유형 A~F 6단계 분류 프레임워크 타당
- `.cursorignore` 파일 생성 및 인덱싱 재실행 절차 정확
- `Cmd+Shift+P → "Cursor: Reindex Codebase"` 커맨드 팔레트 사용법 정확
- Agent 즉시 중단(Esc) 및 Git 복구(`git checkout -- [파일]`) 정확
- BYO API Key 설정 위치 (`Cursor Settings → Models → API Keys`) 정확
- Anthropic Key 접두사 `sk-ant-`, OpenAI Key 접두사 `sk-` 정확
- Anthropic 콘솔 URL (`console.anthropic.com/api-keys`) 정확
- OpenAI 플랫폼 URL (`platform.openai.com/api-keys`) 정확
- SvelteKit `browser` import 및 `onMount` 활용법 정확
- NestJS DI 오류 해결 (PrismaModule imports, @Global(), forwardRef) 정확
- Prisma P3006, P2002, P2025 에러 코드 정확
- CORS `enableCors` 설정 (credentials, methods, allowedHeaders) 정확
- Docker 컨테이너 연결 문제 해결 절차 정확
- Git 비상 복구 절차 (diff, checkout, reset, revert) 정확
