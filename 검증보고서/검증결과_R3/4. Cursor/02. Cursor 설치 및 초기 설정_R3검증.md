### 🟢 확인됨 (정확)
- macOS 설정 경로 `~/Library/Application Support/Code/User/` 정확 (R1 수정 완료)
- Cursor 설정 위치 `~/.cursor/User/settings.json` 정확
- Agent 단축키 Cmd+I 정확 (R1 수정 완료)
- Chat 단축키 Cmd+L 정확
- Inline Edit 단축키 Cmd+K 정확
- Homebrew 설치 명령 `brew install --cask cursor` 정확
- CLI 심볼릭 링크 설정 방법 정확
- Tab 기능 활성화 설정 위치 설명 정확
- Privacy Mode 설정 경로 정확
- pnpm 설치 명령 정확
- Node.js 버전 권장(v18 LTS 이상) 정확
