## 잔존/신규 발견 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| Rules 파일 형식 | `.cursor/rules/*.md` 파일에 YAML frontmatter(`globs:`) 사용 | 현행 Cursor 공식 방식은 `.cursor/rules/*.mdc` 확장자 사용. `.md` 파일에 frontmatter 적용은 구버전 동작 방식이거나 미지원. 독자가 `.md`로 만들면 Auto Attached가 동작하지 않을 수 있음 | 2.1절, 3.2절, 전체 |
| Always On 단일 파일 경로 | `.cursor/rules` (확장자 없는 파일)로 Always On 구현 | 현행 Cursor에서 Always On 방식은 `.cursor/rules/*.mdc` 파일에서 `alwaysApply: true` frontmatter로 설정. 확장자 없는 단일 파일 방식은 레거시 동작이거나 미지원일 수 있음 | 3.1절, 92번째 줄 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| 글로벌 Rules 경로 | `~/.cursor/rules` | 글로벌 Rules 설정 경로는 Cursor 공식 문서에서 명확히 문서화되지 않은 경우 있음. UI 설정(Cursor Settings → Rules)을 통한 글로벌 Rules 설정과 파일 경로 방식 혼재 가능 | 2.1절, 2.3절 |
| Notepads 경로 | `.cursor/notepads/` 폴더 언급 없음 | Cursor Notepads는 `.cursor/notepads/` 폴더에 `.md` 파일로도 관리 가능하나 교재가 UI 방식만 설명 | 7.2절 |
| mkdir 명령어 | `touch .cursor/rules` | `touch` 명령으로 확장자 없는 파일 생성. 현행 방식에서는 `mkdir -p .cursor/rules` 후 `.mdc` 파일 생성이 올바름 | 빠른 시작 가이드 |
