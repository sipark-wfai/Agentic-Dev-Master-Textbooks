### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| $extends 내 `this` 참조 | `return (this as any).update({...})` / `return (this as any).updateMany({...})` | Prisma `$extends` Query Extension 콜백 내부에서 `this`로 같은 모델을 재귀 호출하는 것은 공식 권장 패턴이 아님. `query(args)` 파라미터를 통해 처리하거나, 별도 PrismaClient 인스턴스를 사용하는 방식이 안전 | 8.4절 PrismaService |
| Background Agent 설정 경로 | `Cursor Settings → Features → Background Agent → Enable` | Background Agent는 실험적 기능으로 버전에 따라 위치·명칭이 다를 수 있음. "버전에 따라 다를 수 있음" 명시 필요 | 4.1절 |
| Agent 도구 목록 | 파일 읽기/쓰기/삭제, 터미널 실행, 웹 검색 | 웹 검색 도구는 MCP 또는 @Web 멘션을 통해 제공되는 것으로 Agent 기본 도구가 아닐 수 있음. 버전별 차이 존재 | 1.2절 |
