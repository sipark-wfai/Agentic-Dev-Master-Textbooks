## 6. 연구 활용 권고 (최종)

### 핵심 발견 (연구 논문 활용)

1. **AI 검증의 지식 컷오프 문제**: AI로 AI 생성 콘텐츠 검증 시 검증 모델의 지식 컷오프가 결과에 직접 영향. 신규 출시 도구는 반드시 웹 검색 병행 필요
2. **할루시네이션 유형 분류체계**:
   - Type A: 명칭 오류 (ag→agy, 경로 오류) — 즉시 검출 가능
   - Type B: Deprecated API (Prisma $use, Docker Compose version) — 버전 인식 필요
   - Type C: 미확인 기능 창작 (Proposal System, Timemachine) — 전문 지식 필요
   - Type D: 수치 부정확 (요금, 날짜, 버전) — 공식 소스 대조 필요
3. **도메인 의존성**: 일반 개발 방법론(PRD, NestJS, Prisma)은 정확도 높음. 특정 신규 도구(Antigravity CLI 명령어)에서 집중 발생
4. **심각도 스펙트럼**: 2섹션 05편(2/10, 명령어 전체 오류) ~ 1섹션 01편(8.5/10)까지 광범위
5. **이중 검증 필요성**: AI 검증 + 인간 전문가 검증 이중 구조 필수
