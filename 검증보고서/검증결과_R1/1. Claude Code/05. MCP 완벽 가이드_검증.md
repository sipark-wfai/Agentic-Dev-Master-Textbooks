# 05. MCP 완벽 가이드 할루시네이션 검증 보고서

**검증일**: 2026-06-05
**원본 파일**: 05. MCP 완벽 가이드.md
**전체 할루시네이션 위험도**: 중간

## 검증 요약
MCP의 개념, 아키텍처, 설정 파일 구조에 대한 설명은 전반적으로 정확하다. 그러나 설정 파일 경로 혼재 문제가 발견된다. 본문에서 `.claude/settings.json`을 Claude Code CLI 기준으로 명시하면서도 실습 단계에서 `claude_desktop_config.json`을 혼용하고 있어 혼란을 줄 수 있다. Docker Compose `version: '3.8'` 필드는 deprecated이다.

## 발견된 할루시네이션 / 오류

### 🔴 심각 (사실과 명백히 다름)
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| Docker Compose version 필드 | `version: '3.8'` | Docker Compose v2에서 `version` 필드는 deprecated. 제거 권장 | 섹션 5.1 |

### 🟡 주의 (불확실하거나 오해 소지)
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| 협업 크레딧 오타 | "Calude Sonnet 4.6" | "Claude Sonnet 4.6"의 오타 | 메타 헤더 |
| 설정 파일 경로 혼재 | 섹션 3.1에서 `.claude/settings.json` 기준 명시 후 섹션 5.2에서 `claude_desktop_config.json` 사용 | Claude Code CLI는 `.claude/settings.json`이 맞음. `claude_desktop_config.json`은 Claude Desktop 앱 전용. 혼재하여 오해 가능 | 섹션 3.1, 5.2 |
| 설정 파일 디버깅 경로 | `cat ~/.config/claude/claude_desktop_config.json` | 이는 Claude Desktop 앱 설정 경로로 Claude Code CLI와 다름 | 섹션 6.2 |
| MCP 서버 --debug 옵션 | `npx -y @modelcontextprotocol/server-postgres ... --debug` | `--debug` 옵션 지원 여부는 서버별로 다를 수 있음 | 섹션 6.1 |
| CLAUDE_LOG_LEVEL 환경변수 | `CLAUDE_LOG_LEVEL=debug claude` | 이 환경변수의 실제 존재 여부 불확실 | 섹션 6.3 |
| MCP 로그 경로 | `~/.claude/logs/mcp_*.log` | 실제 로그 파일 경로는 시스템마다 다를 수 있음 | 섹션 6.3 |

### 🟢 확인됨 (정확한 정보)
- MCP(Model Context Protocol) 개념 및 Anthropic 공개 사실 (정확)
- JSON-RPC 2.0 기반 통신 (정확)
- stdio, SSE 두 가지 전송 방식 (정확)
- `.claude/settings.json` Claude Code CLI 설정 파일 위치 (정확)
- `npx -y @modelcontextprotocol/server-postgres` 패키지명 (정확)
- `@modelcontextprotocol/server-git`, `@modelcontextprotocol/server-filesystem` 패키지명 (정확)
- `@modelcontextprotocol/sdk/server/index.js` SDK 임포트 경로 (정확)
- MCP 서버의 ListTools, CallTool 핸들러 패턴 (정확)
- StdioServerTransport 사용법 (정확)

## 개선 권고사항
1. 메타 헤더의 "Calude"를 "Claude"로 수정
2. 섹션 5.2의 `claude_desktop_config.json`을 `.claude/settings.json`으로 일관되게 통일하고 차이점 명확히 설명
3. Docker Compose `version: '3.8'` 필드 제거 (deprecated)
4. 섹션 6.2, 6.3의 Claude Desktop 경로를 Claude Code CLI 경로로 수정

- **점수**: 7.5/10
