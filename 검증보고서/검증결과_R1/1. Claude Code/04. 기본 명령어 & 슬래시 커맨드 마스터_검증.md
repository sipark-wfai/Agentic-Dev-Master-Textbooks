# 04. 기본 명령어 & 슬래시 커맨드 마스터 할루시네이션 검증 보고서

## 검증 요약
실제로 존재하지 않거나 확인되지 않은 CLI 옵션과 슬래시 커맨드가 다수 포함되어 있다. `--headless`, `--timeout`, `/status`, `/bug`, `/tools`, `/cd`, `/history` 등은 실제 Claude Code에 존재하지 않거나 미확인이다. 모델명(`claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-4-5`)도 실제 모델명과 다를 수 있다. 이 편은 가장 주의가 필요한 파일이다.

## 발견된 할루시네이션 / 오류

### 🔴 심각 (사실과 명백히 다름)
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| --headless 옵션 | `claude --headless "작업"` | Claude Code에 `--headless` 옵션이 공식 존재하지 않음. `-p` 또는 `--print`가 비대화형 실행에 사용됨 | 섹션 2.5 |
| --timeout 옵션 | `claude --headless --timeout 300 "..."` | `--timeout` 옵션 존재하지 않음 | 섹션 2.5 |
| /status 커맨드 | `> /status` | 실제 Claude Code에 `/status` 커맨드 존재하지 않음 | 섹션 3.9 |
| /bug 커맨드 | `> /bug "버그 내용"` | 실제 Claude Code에 `/bug` 커맨드 존재하지 않음 | 섹션 3.7 |
| /tools 커맨드 | `> /tools` | 실제 Claude Code에 `/tools` 커맨드 존재하지 않음 | 섹션 3.9 |
| /cd 커맨드 | `> /cd /path/to/other/folder` | 실제 Claude Code에 `/cd` 커맨드 존재하지 않음 | 섹션 3.9 |
| /history 커맨드 | `> /history` | 실제 Claude Code에 `/history` 커맨드 존재하지 않음 | 섹션 3.9 |

### 🟡 주의 (불확실하거나 오해 소지)
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| 협업 크레딧 오타 | "Calude Sonnet 4.6" | "Claude Sonnet 4.6"의 오타 | 메타 헤더 |
| 모델명 | `claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-4-5` | 실제 모델명은 `claude-opus-4-5`는 존재하나 나머지 두 모델명도 확인 필요. 형식은 맞으나 버전 번호 정확성 불확실 | 섹션 2.3 |
| --silent 옵션 | `claude --print --silent "..."` | `--silent` 옵션 존재 여부 불확실 | 섹션 2.2 |
| /review 커맨드 | `> /review @파일경로` | /review는 실제 존재하나 `@파일경로` 인수 지원 여부 불확실 | 섹션 3.6 |

### 🟢 확인됨 (정확한 정보)
- `claude` 대화형 시작, `claude "메시지"` 일회성 실행 (정확)
- `claude --print "질문"` 출력 전용 실행 (정확)
- `--model` 옵션으로 모델 지정 (정확)
- `--resume` 이전 세션 재개 (정확)
- `/help` 도움말 커맨드 (정확)
- `/clear` 대화 초기화 (정확)
- `/compact` 히스토리 압축 (정확)
- `/cost` 비용 확인 (정확)
- `/memory` 메모리 조회 (정확)
- `/vim` vim 키바인딩 (정확)
- `/model {모델명}` 모델 변경 (정확)
- `@파일경로` 컨텍스트 지시어 (정확)
- `--allowedTools`, `--disallowedTools` 옵션 (정확)
- `Shift+Enter` 멀티라인 입력 (정확)
- `Ctrl+C` 작업 중단 (정확)

## 개선 권고사항
1. 존재하지 않는 옵션(`--headless`, `--timeout`, `--silent`, `--output-format`) 제거 또는 검증 후 수정
2. 존재하지 않는 슬래시 커맨드(`/status`, `/bug`, `/tools`, `/cd`, `/history`) 제거
3. 모델명을 Anthropic 공식 문서 기준으로 검증하여 수정
4. CI/CD 활용 예시는 `--print` 옵션 기반으로 재작성

## 전체 신뢰도 점수
- **점수**: 5.5/10
- **근거**: 존재하지 않는 CLI 옵션과 슬래시 커맨드가 다수 포함되어 있어 독자가 실제로 사용할 경우 작동하지 않을 가능성이 높다. 핵심 기능(대화형 실행, @컨텍스트, /clear, /compact 등)은 정확하나 확장 기능 설명에 심각한 오류가 있다.
