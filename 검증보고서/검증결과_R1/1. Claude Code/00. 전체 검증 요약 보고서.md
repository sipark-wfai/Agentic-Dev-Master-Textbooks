## 교재 전체 공통 오류 패턴

### 1. 반복 오타 (전 15편)
- **원문**: "Calude Sonnet 4.6"
- **수정**: "Claude Sonnet 4.6"
- **영향**: 모든 편 메타 헤더에 동일하게 발생

### 2. Hooks 변수 치환 방식 오류 (06, 13편 주요 / 01편 포함)
- **원문**: `"command": ".claude/hooks/script.sh \"${file}\""` 또는 `${command}` 직접 치환
- **실제**: Claude Code Hooks는 tool_input을 **stdin JSON으로 전달**. `${file}`, `${command}` 직접 치환 미지원
- **영향**: Hook 스크립트가 실제 동작하지 않음

### 3. 존재하지 않는 CLI 옵션 (04, 15편)
- **원문**: `--headless`, `--timeout`, `--silent`, `--output-format`
- **실제**: 해당 옵션들 미존재. `--print`가 비대화형 실행의 올바른 옵션
- **영향**: 독자가 옵션 사용 시 오류 발생

### 4. 존재하지 않는 슬래시 커맨드 (04편)
- **원문**: `/status`, `/bug`, `/tools`, `/cd`, `/history`
- **실제**: 해당 커맨드들 실제 Claude Code에 미존재
- **영향**: 독자가 사용 시 오류 발생

### 5. Docker Compose version 필드 deprecated (05, 12편)
- **원문**: `version: '3.8'`
- **실제**: Docker Compose v2에서 `version` 필드 deprecated. 경고 발생
- **영향**: 직접적 오류는 아니나 best practice 위반

### 6. 설정 파일 경로 혼재 (05, 14편)
- **원문**: `.claude/settings.json`과 `claude_desktop_config.json` 혼용
- **실제**: Claude Code CLI는 `.claude/settings.json` 사용. `claude_desktop_config.json`은 Claude Desktop 앱 전용
- **영향**: 독자 혼란 유발

### 7. Prisma $use() deprecated (11편)
- **원문**: `this.$use(async (params, next) => {...})`
- **실제**: Prisma v5에서 `$use()` 미들웨어 deprecated. `$extends()` query extension 사용 권장
- **영향**: Prisma v5 사용 시 경고 또는 오류

### 8. 모델명 불확실성 (04, 07, 14, 15편)
- **원문**: `claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-4-5`
- **실제**: 일부 모델명은 실제 Anthropic 모델명과 다를 수 있음. 공식 문서 확인 필요
- **영향**: 잘못된 모델명 사용 시 API 오류

## 종합 평가

이 교재는 Claude Code를 처음 접하는 대학생과 신입 개발자를 위한 에이전틱 개발 입문 자료로서 **개념 설명의 정확성이 높고 실용적인 예제가 풍부**하다.

**강점**:
- ReAct 루프, MCP, 멀티에이전트 등 핵심 개념이 명확하고 정확함
- NestJS + Prisma + SvelteKit 실전 코드 예시의 대부분이 기술적으로 정확함
- 마일스톤 분할, PRD 작성법 등 방법론이 체계적임

**약점**:
- CLI 명령어 편(04편)에 존재하지 않는 옵션/커맨드 다수 포함
- Hooks 편(06, 13편)의 변수 치환 방식이 실제 동작 방식과 다름
- 전 편에 걸친 동일 오타와 반복적 deprecated 코드 패턴

**권고**: 04편과 06편은 즉각적인 수정이 필요하며, 전 편의 반복 오타는 일괄 처리가 가능하다. 수정 후 교재의 신뢰도는 **9/10 수준**으로 향상될 것으로 예상된다.
