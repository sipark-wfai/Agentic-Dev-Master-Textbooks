## 검증 요약

13편은 테스트 자동화, 코드 리뷰, CI/CD 파이프라인 구성을 다루는 품질 관리 편이다. GitHub Actions 워크플로우에서 구식 버전과 pnpm filter 명령어 중복 오류가 발견되었다.

## 발견된 할루시네이션 / 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| pnpm 필터 명령어 중복 | pnpm -r --filter backend exec tsc --noEmit | -r(recursive)과 --filter는 동시 사용 시 의미가 충돌. 올바른 명령어는 pnpm --filter backend exec tsc --noEmit (-r 없이) | CI 파이프라인 Type check 단계 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| GitHub Actions 버전 - pnpm | pnpm/action-setup@v3 | 최신은 v4. 05편과 동일한 문제 | 7.1절 CI yml |
| GitHub Actions 버전 - codecov | codecov/codecov-action@v4 | v4는 정확하나 token 파라미터가 required로 변경됨 | 7.1절 CI yml |
| OWASP Dependency Check | dependency-check/Dependency-Check_Action@main | @main 브랜치 참조는 불안정. 특정 태그/버전 참조 권고 | 7.1절 보안 스캔 |
| Render 배포 액션 | johnbeynon/render-deploy-action@v0.0.8 | 해당 액션의 최신 유지 여부 확인 필요 | 7.2절 배포 yml |
| Jest 커버리지 임계값 | coverageThresholds (branches: 70, functions: 80) | jest.config.ts에 coverageThresholds가 아닌 coverageThreshold (단수)가 올바른 키 이름 | 8.1절 |

### 🟢 확인됨
- Auth 서비스 단위 테스트 패턴 (jest.fn().mockResolvedValue 사용)
- Playwright E2E 테스트 기본 설정 방식
- GitHub Actions 단계별 구조 (detect-changes, backend-ci, frontend-ci, security-scan)
- pnpm --filter 패키지별 명령어 실행 방식 (중복 제외)
- 리팩터링 방향 (중복 코드 제거, 유틸 함수 분리)

## 개선 권고사항

1. pnpm -r --filter 중복 명령어 수정: `pnpm -r --filter backend` → `pnpm --filter backend` (확정 오류)
2. Jest 설정 파일에서 coverageThresholds → coverageThreshold로 수정
3. GitHub Actions 버전 최신화 (pnpm@v4)
4. OWASP 액션 버전 핀닝 (@main 대신 특정 태그 사용)
