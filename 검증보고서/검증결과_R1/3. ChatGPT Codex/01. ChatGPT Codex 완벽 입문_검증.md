- AGENTS.md 파일이 Codex의 핵심 규칙 파일인 사실
- 비동기/병렬 실행 지원 사실
- GitHub PR 형태로 결과를 제출하는 방식
- o3/o4-mini 모델 사용 언급

## 개선 권고사항

1. "2024년 Operator" → "2025년 1월 Operator"로 수정 (확정 오류)
2. Antigravity/Google DeepMind 제조사 표기를 "Google"로 단순화
3. 타 도구 비교표의 내용은 출시 시점 명시 권고 (2025.05 기준 등)
