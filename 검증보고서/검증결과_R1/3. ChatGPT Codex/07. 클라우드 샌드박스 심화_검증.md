## 검증 요약

07편은 Ubuntu 22.04 샌드박스 환경의 구조와 패키지 설치, 환경 변수, 네트워크 제한을 다룬다. sudo 없이 apt-get을 사용하는 표현 오류가 발견되었다.

## 발견된 할루시네이션 / 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| apt-get sudo 없이 실행 | "apt-get install -y ffmpeg (샌드박스에서 실행 가능 (sudo 없이))" | Ubuntu에서 apt-get은 기본적으로 root 권한이 필요. 샌드박스가 root로 실행되더라도 "sudo 없이"라는 표현은 혼란을 유발. 정확히는 "root 권한으로 실행 중이므로 sudo 불필요" | 3.3절 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| 샌드박스 실행 시간 | "약 30분" | OpenAI 공식 문서에서 정확한 시간 제한 확인 필요. 정책에 따라 변동 가능 | 7.1절 |
| Docker 사용 가능 | "Docker (제한적)" | 샌드박스 내 Docker 지원 여부는 실제 사용 경험에서 확인 필요 | 2.3절 도구 목록 |
| pg_ctlcluster 버전 | "pg_ctlcluster 16 main start" | PostgreSQL 16이 설치되어 있어야 하며, 샌드박스 기본 설치 여부 확인 필요 | 8.1절 |

### 🟢 확인됨
- Ubuntu 22.04 컨테이너 기반 샌드박스 사실
- 태스크 완료 후 샌드박스 삭제 (임시 파일 제거)
- npm, pnpm, pip, apt 패키지 매니저 사전 설치
- 외부 네트워크 제한 (npm registry, GitHub API는 허용)
- path.join() 사용으로 크로스 플랫폼 호환성 확보 권고
- .gitattributes를 통한 줄 끝 문자 통일 방법

## 개선 권고사항

1. "sudo 없이 apt-get" 표현 수정: "root 권한으로 실행 중이므로 sudo 없이 apt-get 사용 가능" (확정 오류)
2. 샌드박스 실행 시간 제한을 "OpenAI 정책에 따라 변동" 주의 문구 추가
3. Docker 지원 여부에 "확인 필요" 주석 추가
