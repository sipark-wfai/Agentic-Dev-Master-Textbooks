# 02. Codex 환경 설정 완벽 가이드 할루시네이션 검증 보고서

**검증일**: 2026-06-05
**원본 파일**: 02. Codex 환경 설정 완벽 가이드.md
**전체 할루시네이션 위험도**: 중간

## 검증 요약

02편은 ChatGPT Codex의 환경 설정과 GitHub 연동, 첫 태스크 실행을 다루는 실습 중심 편이다. 실제 사용자 경험과 다를 수 있는 오류 2가지가 발견되었다.

## 발견된 할루시네이션 / 오류

### 🔴 심각
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| NestJS 프로젝트 초기화 명령어 | `pnpm create @nestjs/app apps/backend 실행` | `pnpm create @nestjs/app`은 존재하지 않는 명령어. 올바른 명령어는 `npm i -g @nestjs/cli && nest new apps/backend` 또는 `npx @nestjs/cli new apps/backend` | 7.2절 태스크 로그 예시 |

### 🟡 주의
| 항목 | 원문 내용 | 실제 사실/우려사항 | 위치 |
|------|----------|------------------|------|
| Plus 플랜 동시 실행 태스크 수 | "3개" | 실제 한도는 OpenAI 정책에 따라 변동될 수 있으며, 공식 문서에서 "3개"로 명시된 확인 불명 | 2절 요금제 비교표 |
| Pro 플랜 태스크 한도 | "제한 없음" | 실제로는 일정 한도 존재할 가능성 있음 (OpenAI 정책 변동) | 2절 요금제 비교표 |
| ChatGPT Team 플랜 | "팀 공유 기능" | Team 플랜의 Codex 기능 상세는 공식 문서에서 확인 필요 | 2절 요금제 비교표 |
| 모바일 앱 Codex 탭 위치 | "하단 탭 또는 메뉴에서 Codex 선택" | 앱 버전에 따라 UI가 다를 수 있음 | 4.2절 |

### 🟢 확인됨
- ChatGPT Plus($20/월) 이상 구독 필요 사실
- GitHub OAuth 연동 절차 (Authorize openai 클릭 방식)
- GitHub App 레포지토리 접근 권한 설정 방법
- pnpm-workspace.yaml을 통한 모노레포 구조 설정
- AGENTS.md 초기 생성 방법

## 개선 권고사항

1. NestJS 초기화 명령어를 올바른 명령어로 수정 (확정 오류): `nest new apps/backend --package-manager pnpm`
2. 요금제 비교표에 "2025년 기준" 같은 날짜 표기 추가
3. 모바일 앱 설명에 "앱 버전에 따라 다를 수 있음" 주의 문구 추가

## 전체 신뢰도 점수
- **점수**: 7/10
- **근거**: NestJS 초기화 명령어 오류는 실습 시 직접 실패를 유발하는 심각한 오류. 나머지 설정 절차는 일반적으로 정확하나 UI 설명이 버전 의존적임.
