## 검증 요약

전반적인 교재 내용은 에이전틱 개발 방법론 측면에서 올바르나, CLI 명령어(`ag` → `agy`)와 일부 설정 경로 오류가 공통으로 발견된다. 실제 Google Antigravity 제품이 실존함을 전제로 재검증한 결과다.

## 발견된 할루시네이션 / 오류

### 🔴 심각 (사실과 명백히 다름)
| 항목 | 원문 내용 | 실제 사실 | 위치 |
|------|----------|----------|------|
| CLI 명령어 | `ag install`, `ag init` 등 | 실제 명령어는 `agy` | 설치 단계 |
| 설정 파일 경로 | `~/.config/antigravity/GEMINI.md` | 실제 `~/.gemini/GEMINI.md` | 초기 설정 |
| 다운로드 URL | 교재 내 특정 URL 제시 | 공식: antigravity.google/download | 설치 섹션 |

## 개선 권고사항

1. 교재 전체에서 `ag` → `agy`로 CLI 명령어 일괄 수정

3. 공식 미확인 기능에는 "실험적 기능" 또는 "확인 필요" 주석 추가
