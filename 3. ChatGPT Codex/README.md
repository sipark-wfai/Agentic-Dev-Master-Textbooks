**"나만의 24시간 AI 코딩 멘토를 만나보세요."**

혼자서 코딩을 독학할 때 가장 힘든 점은 "내가 제대로 짜고 있는 걸까?"라는 불안감과 막혔을 때 물어볼 사람이 없다는 외로움입니다.

본 교재는 **ChatGPT Codex를 나만의 전담 코딩 멘토로 최적화하여 활용하는 방법**을 다룹니다. 코드 한 줄 쓰기 두려운 입문자도 Codex의 강력한 자동 완성 및 최적화 기능을 발판 삼아, 가장 쉽고 빠르게 개발의 즐거움을 느낄 수 있도록 안내합니다.

## 1. 시리즈 소개

### 왜 이 교재 시리즈인가

ChatGPT Codex는 설치가 필요 없다. Node.js를 설치하거나, 앱을 다운로드하거나, API 키를 환경 변수에 등록할 필요가 없다. ChatGPT에 접속하여 "Codex"를 선택하고, GitHub 레포지토리를 연결하고, 자연어로 지시사항을 입력하면 된다. 나머지는 OpenAI 클라우드의 Ubuntu 샌드박스 안에서 에이전트가 처리한다.

이 "설치 없는 진입" 방식은 개발 환경 구성에 낯선 기획자·디자이너에게 특히 매력적이다. 동시에 개발자에게는 다른 종류의 강점을 제공한다. 여러 태스크를 큐에 넣고 에이전트가 백그라운드에서 처리하는 동안 다른 일을 할 수 있다. 8종 게시판 API를 하나씩 구현하는 동안 개발자는 커피를 마신다.

GitHub와의 네이티브 연동도 차별점이다. 코드를 로컬 파일로 받는 것이 아니라, 에이전트가 직접 브랜치를 만들고 커밋하고 PR을 열어 팀에 리뷰 요청을 보낸다. 기획자가 GitHub Issue를 작성하면 Codex가 그것을 읽고 구현하여 PR을 만든다. 이것이 Claude Code·Antigravity와 가장 다른 점이다.

### 이 시리즈로 최종적으로 할 수 있는 것

- ChatGPT Codex와 GitHub를 연동하여 Issue → 자동 구현 → PR 파이프라인을 구축할 수 있다.
- AGENTS.md를 작성하여 에이전트가 프로젝트 규칙을 일관되게 따르도록 통제한다.
- 비동기 멀티태스킹으로 8종 게시판을 병렬로 구현하는 전략을 실행한다.
- SvelteKit + NestJS + PostgreSQL 16 기반의 멀티 게시판 풀스택 서비스를 완성한다.
- GitHub Actions와 Codex를 연동한 CI/CD 자동화 파이프라인을 구축한다.
- Jest·Supertest·Playwright 테스트를 Codex로 자동 작성하고 커버리지를 관리한다.

### STAGE 2 — 핵심 설정·도구 (교재 03~07)

- 프로젝트 규칙·기술 스택·브랜치 전략·금지 사항을 올바르게 작성한다.

**주요 내용**: AGENTS.md vs CLAUDE.md vs GEMINI.md 비교, Codex의 파싱 방식, 필수 섹션(프로젝트 개요·기술 스택·코딩 컨벤션·빌드·테스트·브랜치·금지 사항), 서브 디렉토리 AGENTS.md(모노레포), 멀티 게시판 전체 AGENTS.md 예시, 비교 사례 5가지, 품질 체크리스트

**대상 독자**: 전체 | **선수 교재**: 01·02 | **예상 학습 시간**: 90~120분

**주요 내용**: 지시문 5원칙(목표·범위·성공기준·참조·모델), 유형별 패턴 10가지(신규 기능·버그 수정·리팩터링·테스트·문서화·마이그레이션·리뷰·보안·성능·의존성), PR diff 분석법, 재요청(refinement) 패턴, 멀티 게시판 실전 태스크 5개 예시

**대상 독자**: 전체 | **선수 교재**: 02 | **예상 학습 시간**: 90~120분

#### 교재 05. GitHub 완전 연동

**한 줄 소개**: Issue를 쓰면 Codex가 PR을 만든다. GitHub와 Codex의 완전한 통합을 구축한다.

**학습 목표**:
- GitHub Issue → Codex 태스크 → PR 자동화 파이프라인을 완성한다.
- 브랜치 보호 규칙을 설정하고 Codex PR도 반드시 리뷰를 거치도록 강제한다.
- GitHub Actions를 Codex와 연동하여 자동 트리거를 구성한다.

**주요 내용**: GitHub ↔ Codex 연동 아키텍처, Issue → 태스크 전환, 브랜치 자동 생성 패턴, PR 자동 생성, 브랜치 보호 규칙, GitHub Actions 연동, 팀 코드 리뷰 프로세스, 모노레포 환경 연동, 멀티 게시판 Issue → PR 자동화 워크플로우

**대상 독자**: 개발자·기획자 | **선수 교재**: 02·03 | **예상 학습 시간**: 90~120분

#### 교재 06. 비동기 멀티태스킹

**한 줄 소개**: 에이전트가 일하는 동안 개발자는 딴 일을 한다. 병렬 태스크 전략을 익힌다.

**학습 목표**:
- 태스크 큐를 효과적으로 관리하는 전략을 수립한다.

- 8종 게시판 API를 병렬 태스크로 분산 구현하는 계획을 실행한다.

**주요 내용**: 비동기 실행 장점, 태스크 큐 관리(Pending·Running·Completed·Failed), 독립·의존 태스크 구분, 우선순위 설정, 완료 알림 설정(이메일·슬랙·GitHub), 태스크 취소·재시작, 비용 관리, 멀티 게시판 8종 병렬 구현 계획

**대상 독자**: 개발자 | **선수 교재**: 04·05 | **예상 학습 시간**: 90~120분

#### 교재 07. 클라우드 샌드박스 심화

**한 줄 소개**: Codex가 일하는 Ubuntu 환경을 이해하면 태스크 실패를 미리 막을 수 있다.

**학습 목표**:
- Ubuntu 22.04 클라우드 샌드박스의 구조와 제약을 이해한다.
